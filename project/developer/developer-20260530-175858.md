# Developer — Output

Создание рекламного проспекта в PDF формате, содержащего сравнительный анализ проекта CraftStack и Paperclip, требует использования библиотек для генерации PDF-документов. В данном ответе я предоставлю пример кода на Node.js с использованием библиотеки PDFKit для создания такого документа. 

Сначала убедитесь, что у вас установлен Node.js и библиотека PDFKit:

```bash
npm install pdfkit
```

Теперь создадим файл `generateBrochure.js` в проекте, который будет создавать PDF-документ:

```javascript
const PDFDocument = require('pdfkit');
const fs = require('fs');

const doc = new PDFDocument();

doc.pipe(fs.createWriteStream('CraftStack_Brochure.pdf'));

// Заголовок
doc.fontSize(25).text('Промо проспект проекта CraftStack', { align: 'center' });
doc.moveDown();

// Введение
doc.fontSize(14).text('CraftStack - это мощный и эффективный инструмент для разработчиков, который предлагает гибкие возможности для создания и управления проектами.');
doc.moveDown();

// Сравнение с Paperclip
doc.fontSize(20).text('Сравнение с Paperclip', { underline: true });
doc.moveDown();

const comparisonTable = [
    { feature: 'Функция', craftStack: 'Гибкое управление проектами', paperclip: 'Ограниченные функции' },
    { feature: 'Поддержка', craftStack: '24/7 поддержка', paperclip: 'Непостоянная поддержка' },
    { feature: 'Интерфейс', craftStack: 'Современный и отзывчивый', paperclip: 'Старый и неудобный' },
];

// Заголовок таблицы
doc.fontSize(12).text('Функции             | CraftStack                   | Paperclip');
doc.moveDown();

comparisonTable.forEach(row => {
    doc.text(`${row.feature.padEnd(20)} | ${row.craftStack.padEnd(30)} | ${row.paperclip}`);
    doc.moveDown();
});

// График
doc.addPage()
   .fontSize(16)
   .text('Сравнение производительности:', { align: 'center' });
doc.image('path/to/your/graph.png', { fit: [500, 400], align: 'center', valign: 'center' });
doc.moveDown();

// Заключение
doc.addPage()
   .fontSize(14)
   .text('В заключение, CraftStack предлагает более мощный набор инструментов для разработчиков, обеспечивая высокое качество поддержки и удобство работы.', { align: 'justify' });

doc.end();
```

Замените `'path/to/your/graph.png'` на путь к изображению графика, которое вы хотите включить в pdf.

После того, как вы создадите этот файл, вы можете запустить его с помощью Node.js:

```bash
node generateBrochure.js
```

Это создаст PDF-документ `CraftStack_Brochure.pdf` в текущей директории.

Пожалуйста, помните, что вы также можете дополнительно украсить ваши страницы, добавив больше элементов дизайна, таких как логотип, фон и т.д., используя методы PDFKit. Однако это основной шаблон для создания вашего промо проспекта.
