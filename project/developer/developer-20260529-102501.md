# Developer — Output

Для того чтобы доработать web-приложение ai-hub.html так, чтобы ваши записи сохранялись в памяти, а заполнение данных могло проходить без полного заполнения, нам нужно будет сохранить данные на стороне клиента, например, используя Local Storage. Кроме того, мы сделаем поля необязательными, чтобы пользователь мог оставить некоторые из них пустыми.

Вот пример кода, который будет содержать нужный функционал:

### ai-hub.html

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>AI Hub</title>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <div class="container">
        <h1>Записи AI Hub</h1>
        <form id="noteForm">
            <label for="title">Заголовок:</label>
            <input type="text" id="title" placeholder="Введите заголовок"><br>
            
            <label for="content">Содержание:</label>
            <textarea id="content" placeholder="Введите содержание"></textarea><br>
            
            <button type="submit">Сохранить запись</button>
        </form>
        
        <h2>Ваши записи:</h2>
        <div id="notesList"></div>
    </div>

    <script src="scripts.js"></script>
</body>
</html>
```

### scripts.js

```javascript
document.addEventListener('DOMContentLoaded', () => {
    const form = document.getElementById('noteForm');
    const titleInput = document.getElementById('title');
    const contentInput = document.getElementById('content');
    const notesList = document.getElementById('notesList');

    // Загрузка записей из Local Storage
    loadNotes();

    form.addEventListener('submit', (e) => {
        e.preventDefault();

        const title = titleInput.value;
        const content = contentInput.value;
        
        if (title || content) { // Сохраняем, если хотя бы одно поле заполнено
            const note = { title, content };
            saveNote(note);
        }

        titleInput.value = '';
        contentInput.value = '';
        loadNotes(); // Обновляем список записей
    });

    function saveNote(note) {
        let notes = JSON.parse(localStorage.getItem('notes')) || [];
        notes.push(note);
        localStorage.setItem('notes', JSON.stringify(notes));
    }

    function loadNotes() {
        notesList.innerHTML = ''; // Очищаем текущий список
        let notes = JSON.parse(localStorage.getItem('notes')) || [];

        notes.forEach(note => {
            const noteItem = document.createElement('div');
            noteItem.classList.add('note-item');
            noteItem.innerHTML = `<h3>${note.title || 'Без заголовка'}</h3><p>${note.content || 'Нет содержания'}</p>`;
            notesList.appendChild(noteItem);
        });
    }
});
```

### Объяснение

1. **HTML-часть**: Создается форма для ввода заголовка и содержания заметки. Загаловок и содержание можно оставить пустыми.

2. **CSS**: простой стиль для лучшего восприятия.

3. **JavaScript**:
   - Записи загружаются из Local Storage при первом открытии страницы.
   - Валидация формы позволяет сохранять запись, даже если поля не все заполнены (хотя бы одно поле должно быть заполнено).
   - После отправки форма очищается, и список сохраняемых записей обновляется.

Теперь ваше приложение сохранит записи между сессиями и позволит пользователю вводить записи, не заполняя все поля.
