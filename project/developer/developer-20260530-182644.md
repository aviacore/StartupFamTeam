# Developer — Output

Для создания рекламного проспекта проекта CraftStack в формате PDF, можно использовать библиотеку для генерации PDF на Python, такую как `FPDF`. Ниже представлен псевдокод на Python, который генерирует PDF-документ с рекламным проспектом, в котором осуществляется сравнение с проектом Paperclip.

### Установка необходимых библиотек
Если у вас еще не установлена библиотека `FPDF`, вы можете установить её с помощью pip:
```bash
pip install fpdf
```

### Код для генерации PDF-проспекта
```python
from fpdf import FPDF

class PDF(FPDF):
    def header(self):
        self.set_font('Arial', 'B', 12)
        self.cell(0, 10, 'CraftStack: Ваш надежный инструмент для управления AI-агентами', 0, 1, 'C')

    def footer(self):
        self.set_y(-15)
        self.set_font('Arial', 'I', 8)
        self.cell(0, 10, f'Страница {self.page_no()}', 0, 0, 'C')

    def chapter_title(self, title):
        self.set_font('Arial', 'B', 12)
        self.cell(0, 10, title, 0, 1, 'L')
        self.ln(5)

    def chapter_body(self, body):
        self.set_font('Arial', '', 12)
        self.multi_cell(0, 10, body)
        self.ln()

pdf = PDF()
pdf.set_auto_page_break(auto=True, margin=15)
pdf.add_page()

# Введение
pdf.chapter_title('Введение')
pdf.chapter_body("CraftStack — это легкий инструмент для управления AI-агентами, "
                 "доступный для стартапов и организаций. Мы предлагаем простоту, "
                 "скорость и эффективность в сравнении с другими решениями, такими как Paperclip.")

# Сравнительная таблица
pdf.chapter_title('Сравнительная таблица')
pdf.set_font('Arial', '', 10)
pdf.cell(40, 10, 'Особенность', 1)
pdf.cell(60, 10, 'CraftStack', 1)
pdf.cell(60, 10, 'Paperclip', 1)
pdf.ln()
pdf.cell(40, 10, 'Зависимости', 1)
pdf.cell(60, 10, 'Отсутствуют', 1)
pdf.cell(60, 10, 'Много, требует Node.js', 1)
pdf.ln()
pdf.cell(40, 10, 'Производительность', 1)
pdf.cell(60, 10, 'Легкий и быстрый', 1)
pdf.cell(60, 10, 'Медленный на CPU', 1)
pdf.ln()
pdf.cell(40, 10, 'Потоковая обработка', 1)
pdf.cell(60, 10, 'SSE для обновлений', 1)
pdf.cell(60, 10, 'WebSocket', 1)
pdf.ln()

# Графики и диаграммы
pdf.chapter_title('Преимущества CraftStack')
pdf.chapter_body("CraftStack предлагает следующие преимущества:")
pdf.chapter_body("- Простота в использовании и настройке\n- Меньше зависимостей, что упрощает развертывание\n"
                 "- Предоставляет уникальные режимы агентов для оптимизации управления задачами\n"
                 "- Подходит для работы на компьютерах без графических ускорителей")

# Вывод
pdf.chapter_title('Заключение')
pdf.chapter_body("Выберите CraftStack и испытайте все преимущества легкого и эффективного инструмента "
                 "для управления вашими AI-агентами. Наслаждайтесь простотой и высокой производительностью!")

# Сохранение PDF
pdf_file_name = 'CraftStack_Prospekt.pdf'
pdf.output(pdf_file_name)

print(f'PDF файл "{pdf_file_name}" успешно создан.')
```

### Инструкции по запуску
1. Установите библиотеку `FPDF`, если она ещё не установлена.
2. Сохраните указанный выше код в файл, например, `create_prospectus.py`.
3. Запустите скрипт, используя Python:
   ```bash
   python create_prospectus.py
   ```
4. После выполнения скрипта в рабочей директории появится файл `CraftStack_Prospekt.pdf`.

### Примечания
- Вы можете доработать графики и диаграммы с помощью существующих библиотек визуализации данных, таких как `matplotlib`, и включить их в PDF.
- Оформление и внешний вид документа можно изменить, добавив больше стилей и элементов, таких как логотип или цветные фоны.
