# Пятнашки — веб-игра

## Концепция
Классическая игра «Пятнашки» (15 puzzle) в виде современного веб-приложения. Поле 4×4, 15 фишек с числами от 1 до 15, одна пустая клетка. Цель — упорядочить фишки по возрастанию.

## Целевая аудитория
- Люди, ностальгирующие по классическим играм
- Пользователи, ищущие «убийцу времени» на 5–10 минут
- Дети и взрослые для тренировки логики

## Функциональность MVP
1. Игровое поле 4×4 с фишками
2. Перемешивание и подсчёт ходов
3. Таймер
4. Проверка победы
5. Кнопка «Новая игра»

## Дополнительно (post-MVP)
6. Таблица рекордов (LocalStorage)
7. Анимация перемещения фишек
8. Адаптивный дизайн
9. Тёмная/светлая тема

## Технологии (для MVP)
- Чистый HTML + CSS + JS (никаких фреймворков)
- Один файл — максимальная простота
- GitHub Pages для хостинга
