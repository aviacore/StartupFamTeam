# План UI/UX для дашборда финансовой аналитики

## 1. Цель дашборда
Дашборд предназначен для визуализации ключевых метрик юнит-экономики, мониторинга прогнозов, контроля KPI и анализа отчётности. Основные пользователи — бизнес-аналитики, продакт-менеджеры, финансовые директора.

## 2. Основные принципы UI/UX
- **Простота и ясность**: минимум кликов до данных, понятная иерархия.
- **Адаптивность**: корректное отображение на десктопах (1920px) и планшетах (1024px).
- **Консистентность**: единый цветовой код (зелёный — хорошо, красный — тревога, серый — нейтрально).
- **Производительность**: данные загружаются в фоне, подгрузка фильтров без перезагрузки страницы.

## 3. Структура и блоки дашборда

### 3.1. Верхняя панель (Header)
- **Логотип и название проекта** (слева).
- **Период отчёта**: выпадающий календарь (month / quarter / year).
- **Глобальный поиск** (по клиентам, продуктам).
- **Аватар пользователя** (справа, с выпадающим меню настроек).

### 3.2. Блок KPI (Top Metrics) — 4 крупные карточки
1. **CAC** (средняя стоимость привлечения клиента) — число, подпись "₽/клиент".
2. **LTV** (пожизненная ценность клиента) — число, подпись "₽".
3. **Маржинальность** (в %) — прогресс-бар с цветом.
4. **Точка безубыточности** (BEP — Break-Even Point) — число клиентов/месяц.

Каждая карточка содержит:
- текущее значение,
- дельта к прошлому периоду (стрелка вверх/вниз, зелёная/красная),
- мини-спарклайн (график тренда за 6 мес.).

### 3.3. График прогноза на 6–12 месяцев (центральный блок)
- **Тип**: комбинированный график (линия + столбцы).
- **Ось X**: месяцы (М1–М12).
- **Ось Y**: доходы (столбцы) и расходы (линия).
- **Переключатель** между 6 и 12 месяцами.
- **Аннотации**: кастомные точки, где пересекаются линии (точка безубыточности, пик LTV).
- При наведении — всплывающая подсказка с деталями (CAC, LTV, маржа).

### 3.4. Таблица «Клиенты и продукты» (нижний блок)
- **Колонки**: ID клиента, продукт, CAC, LTV, маржинальность, статус (активен/спящий/отток).
- **Фильтры** над таблицей: по продукту, по статусу, по диапазону CAC/LTV.
- **Возможность сортировки** по каждой колонке.
- **Пагинация** (25/50/100 записей на странице).
- **Экспорт** в CSV (кнопка справа).

### 3.5. Панель фильтров (левая или выезжающая)
- **Период**: месяц / квартал / год.
- **Продукт**: мультивыбор (чекбоксы).
- **Клиентский сегмент**: B2B / B2C / Enterprise.
- **Сбросить фильтры** (кнопка).

### 3.6. Блок сводной статистики (правый нижний угол или выездная панель)
- **Краткий итог**: количество активных клиентов, средний чек, прогноз выручки на выбранный период.
- **Прогноз окупаемости** (число месяцев до возврата CAC).

## 4. Цветовая схема и типографика
- **Основной фон**: светло-серый (#F5F7FA).
- **Карточки KPI**: белые (#FFFFFF) с тенью (box-shadow).
- **Графики**: синий (#2196F3) — доходы, оранжевый (#FF9800) — расходы, зелёный (#4CAF50) — точка безубыточности.
- **Текст**: основной — #333333, вспомогательный — #666666.
- **Кнопки и акценты**: #1976D2 (кнопка применить фильтры).

**Шрифты**: Inter или Roboto (без засечек, 14px основной текст, 16–18px заголовки блоков).

## 5. Интерактивность и анимация
- **При наведении** на любой элемент (график, карточку, строку таблицы) — лёгкое увеличение тени.
- **Переключение прогноза** (6/12 мес.) — плавная анимация сдвига графика.
- **Фильтры** применяются мгновенно, данные подгружаются без перезагрузки (AJAX).

## 6. Адаптивность
- **Десктоп (1280–1920px)**: всё по умолчанию — широкая сетка, крупные графики.
- **Планшет (768–1024px)**: карточки KPI — 2 в ряд, график под ними, таблица — горизонтальный скролл.
- **Мобильные (<768px)**: KPI — 1 карточка на строку, график — уменьшенный, фильтры — выезжающее полноэкранное меню, таблица — адаптивные колонки (скрыть второстепенные).

## 7. Сценарии использования (User Flows)
1. **Просмотр KPI за текущий месяц**: пользователь открывает дашборд → видит верхние карточки → смотрит динамику.
2. **Анализ прогноза**: переключает на 12 месяцев → видит точку безубыточности → наводит на аннотации для деталей.
3. **Фильтрация по продукту**: открывает левую панель → выбирает продукт → таблица и график обновляются.
4. **Экспорт данных**: в таблице нажимает "Экспорт в CSV" → файл скачивается.

## 8. Технические заметки (для разработчиков)
- Использовать React (Next.js) + D3.js или Recharts для графиков.
- Таблица — виртуализация (react-virtualized) при большом количестве строк.
- Фильтры — Redux или Context API для глобального состояния.
- Данные — REST API (эндпоинты: `/kpi`, `/forecast`, `/table-data`).
