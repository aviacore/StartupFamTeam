```markdown
# План 04: ИИ-агенты для маркетинга

Для реализации маркетинговой стратегии проекта необходимы следующие ИИ-агенты:

1. **Агент анализа ЦА** — сегментирует аудиторию, строит портреты клиентов, определяет каналы привлечения.
2. **Агент контент-маркетинга** — генерирует тексты для блогов, лендингов, email-рассылок, адаптирует под tone of voice.
3. **Агент таргетированной рекламы** — подбирает ключевые слова, создает объявления, оптимизирует ставки (для Яндекс.Директ, VK Реклама, Telegram Ads).
4. **Агент аналитики лидов** — отслеживает источники трафика, качество заявок, рассчитывает CAC на канал.
5. **Агент SMM** — планирует посты, генерирует визуалы, анализирует вовлеченность в соцсетях.
6. **Агент A/B-тестирования** — автоматически запускает сплит-тесты креативов, заголовков, CTA.
7. **Агент отчетности** — еженедельно собирает KPI (CAC, LTV, конверсия) и отправляет summary в Telegram/email.

Файл сохранен в папке `project` под именем `Plan_04.md`.
```
