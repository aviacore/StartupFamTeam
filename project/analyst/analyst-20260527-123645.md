## 2. Расчёт юнит-экономики (Unit Economics)

### 2.1. Допущения (Assumptions)

Для расчётов я принимаю следующие вводные, основанные на данных Marketer и Developer:

| Параметр | Значение | Источник |
|----------|----------|----------|
| Количество команд в Pro | 20 агентов | Marketer (Pro план) |
| Средний размер команды | 10 человек | Маркетинговое исследование (микрокоманды 2-10 чел.) |
| Цена Pro ($/мес) | $9 | Marketer |
| Цена Enterprise ($/мес) | $49 | Marketer |
| Cost per Lead (CPL) | $1 | Оценка (контекстная реклама / LinkedIn) |
| Conversion Rate (CR) | 5% | Средний CR для B2B SaaS |
| Churn Rate (отток) | 5% в месяц | Средний для micro-SaaS |
| Server cost (Node.js + SQLite) | $10/мес | Hosting на Railway.app / Fly.io |
| Development cost (разработчик) | $50/час | Рыночная ставка (Developer из команды) |
| Маржа на Freemium | 0% (бесплатно) | |
| Маржа на Pro | 80% | (9 - 1.8 затраты) / 9 |

### 2.2. Расчёт CAC (Customer Acquisition Cost)

**Метод:** Paid acquisition (контекстная реклама + LinkedIn)

```
CAC = (CPL × количество лидов) / количество клиентов
CAC = ($1 × 100 лидов) / (100 лидов × 5% CR) = $100 / 5 = $20
```

**Итог:** CAC = **$20 на одного платящего пользователя Pro**.

### 2.3. Расчёт LTV (Lifetime Value)

**Метод:** LTV = ARPU × Gross Margin × (1 / Churn Rate)

- ARPU (Pro) = $9/мес
- Gross Margin (Pro) = 80% (0.8)
- Churn Rate = 5% в месяц (0.05)

```
LTV = $9 × 0.8 × (1 / 0.05) = $7.2 × 20 = $144
```

**LTV для Enterprise:**
- ARPU (Enterprise) = $49/мес
- Gross Margin = 85% (меньше затрат на поддержку)
- Churn = 3% (корпоративные клиенты уходят реже)

```
LTV (Enterprise) = $49 × 0.85 × (1 / 0.03) = $41.65 × 33.3 = $1,387
```

**Итог:**
- **LTV (Pro):** $144
- **LTV (Enterprise):** $1,387

### 2.4. Соотношение LTV/CAC

- **Pro:** LTV/CAC = $144 / $20 = **7.2x** ✅ (отлично, > 3x — зелёная зона)
- **Enterprise:** LTV/CAC = $1,387 / $20 = **69.35x** ✅ (превосходно, но CAC для Enterprise может быть выше)

**Вывод:** Юнит-экономика положительная. Каждый вложенный доллар в маркетинг окупается в 7 раз на Pro и в 69 раз на Enterprise.

## 3. Финансовая модель и точка безубыточности

### 3.1. Постоянные затраты (Fixed Costs)

| Статья | Сумма ($/мес) |
|--------|---------------|
| Сервер (Node.js + SQLite) | $10 |
| Домен (rollcall.ai) | $2 |
| Разработка (10 часов/мес поддержки) | $500 |
| Маркетинг (тестовая реклама) | $200 |

**Total Fixed Costs:** $712/мес

### 3.2. Точка безубыточности (Break-Even Point, BEP)

**Формула:** BEP = Fixed Costs / (ARPU - Variable Costs per user)

- Variable Costs на одного Pro-юзера: $1.8 (20% от $9 — хостинг, поддержка)
- Contribution Margin = $9 - $1.8 = $7.2

```
BEP = $712 / $7.2 = 98.9 ≈ 99 платящих пользователей Pro
```

**Или в выручке:** 99 × $9 = **$891/мес**

**Вывод:** Чтобы покрыть все затраты, нужно **99 платящих пользователей Pro** (или 15 Enterprise + 20 Pro). При текущем CR (5%) и CAC ($20) это потребует:
- Лидов: 99 / 0.05 = **1,980 лидов**
- Бюджет на рекламу: 1,980 × $1 = **$1,980**

### 3.3. Срок окупаемости (Payback Period)

**Формула:** Payback = Fixed Costs / (Monthly Revenue - Monthly Costs)

При 99 пользователях Pro:
- Monthly Revenue = 99 × $9 = $891
- Monthly Costs = $712 (fixed) + 99 × $1.8 (variable) = $712 + $178 = $890

**Payback = $1,980 / ($891 - $890) = ∞** (на грани). Чтобы быть устойчивыми, нужно либо:
1. Снизить CAC (например, до $0.5 — органический трафик).
2. Увеличить ARPU (например, $15/мес для Pro).
3. Комбинировать: 50 Pro + 5 Enterprise.

**Сценарий с комбинацией:**
- 50 Pro ($450/мес) + 5 Enterprise ($245/мес) = $695/мес
- Затраты: $712 + (50 × $1.8 + 5 × $7.35) = $712 + $90 + $36.75 = $838.75
- **Убыток:** $695 - $838.75 = -$143.75/мес → нужен третий месяц или рост до 60 Pro.

**Оптимальный сценарий (без убытка):**
- 70 Pro ($630) + 5 Enterprise ($245) = $875/мес
- Затраты: $712 + (70 × $1.8 + 5 × $7.35) = $712 + $126 + $36.75 = $874.75
- **Прибыль:** $0.25/мес (чистая точка безубыточности)
