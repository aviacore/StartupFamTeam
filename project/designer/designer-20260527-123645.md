# Designer — Output

Как UI/UX Designer, я внимательно изучил работу всех предыдущих агентов. Вижу чёткую задачу от PM, надёжную архитектуру от CTO и рабочий код от Developer. Но сейчас всё это выглядит как сырой инструмент для разработчиков. У нас есть функциональность, но нет **пользовательского опыта и визуальной целостности**. CEO видит серый HTML, разработчик запускает скрипты в терминале — это не продукт, это прототип.

Моя задача — превратить это в **продукт, которым приятно пользоваться**. Я добавлю:

1. **Тёмную тематику** (профессионально, современно, меньше усталости глаз).
2. **Отзывчивый интерфейс** (работает на мобильном CEO, планшете PM, большом экране разработчика).
3. **Анимации и микро-взаимодействия** (отклик на действия, живая лента статусов).

Я не буду трогать логику backend'а или SQLite — они отличные. Я изменю только **frontend-часть**: `style.css`, `index.html`, `app.js`, а также добавлю **брендинг** (цвета, шрифты, иконки).

### 2. Тёмная тема: палитра

Я выбрал гармоничную тёмную палитру с акцентами:

- **Фон:** `#0f172a` (Slate-900) — глубокий тёмно-синий, не утомляет.
- **Карточки:** `#1e293b` (Slate-800) — контрастный фон для контента.
- **Текст основной:** `#e2e8f0` (Slate-200) — мягкий белый.
- **Текст вторичный:** `#94a3b8` (Slate-400) — для меток.
- **Акцентный цвет (CEO/Primary):** `#3b82f6` (Blue-500) — кнопки, ссылки.
- **Акцент готовности (Success):** `#22c55e` (Green-500) — статус "готов".
- **Ошибка (Error):** `#ef4444` (Red-500) — статус "не отвечает".
- **Предупреждение (Warning):** `#eab308` (Yellow-500) — статус "в процессе".

                </div>

        agentList.appendChild(item);
    });
}

// Обновление статуса одного агента в UI
function updateAgentStatus(agentId, status, message) {
    const item = document.getElementById(`agent-${agentId}`);
    if (!item) return;

    // Сбрасываем предыдущие классы
    item.className = 'agent-item';

    const dot = item.querySelector('.dot');
    const statusText = item.querySelector('.status-text');

    switch(status) {
        case 'ready':
            item.classList.add('ready');
            dot.className = 'dot ready';
            statusText.textContent = `✅ Готов: ${message || 'Жду задачи'}`;
            break;
        case 'offline':
            item.classList.add('offline');
            dot.className = 'dot offline';
            statusText.textContent = '❌ Не отвечает (offline)';
            break;
        case 'pending':
            item.classList.add('pending');
            dot.className = 'dot pending';
            statusText.textContent = '⏳ Отвечает...';
            break;
        default:
            item.classList.add('idle');
            dot.className = 'dot idle';
            statusText.textContent = '⏸ Ожидание';
    }

    // Анимация появления статуса
    item.style.animation = 'none';
    requestAnimationFrame(() => {
        item.style.animation = 'fadeInUp 0.3s ease';
    });
}

// Установка статуса "pending" всем агентам
function setAllPending() {
    AGENTS.forEach(agent => {
        updateAgentStatus(agent.id, 'pending');
    });
}
