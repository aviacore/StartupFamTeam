# Designer — Output

Хорошо! Давайте разработаем простое веб-приложение с современным дизайном и функционалом. Мы создадим интерфейс для ввода данных о провайдерах, таких как название провайдера/модели, адрес сайта, API-ключ и остаток денег. Для этого я представлю HTML, CSS и немного JavaScript.

### 1. HTML (index.html)

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <link rel="stylesheet" href="styles.css">
    <title>Провайдеры</title>

    <div class="container">
        <h1>Список провайдеров</h1>
        <form id="provider-form">
            <input type="text" id="provider-name" placeholder="Название провайдера" required>
            <input type="url" id="website" placeholder="Адрес сайта" required>
            <input type="text" id="api-key" placeholder="API-ключ" required>
            <input type="number" id="balance" placeholder="Остаток средств" required>
            <button type="submit">Добавить провайдера</button>
        </form>
        <table id="provider-table">
            <thead>
                <tr>
                    <th>Провайдер</th>
                    <th>Сайт</th>
                    <th>API-ключ</th>
                    <th>Остаток</th>
                </tr>
            </thead>
            <tbody>
                <!-- Здесь будут строки с провайдерами -->
            </tbody>
        </table>
    </div>
    <script src="script.js"></script>
</body>
</html>
```

### 3. JavaScript (script.js)

```javascript
document.getElementById('provider-form').addEventListener('submit', function(event) {
    event.preventDefault();

    const name = document.getElementById('provider-name').value;
    const website = document.getElementById('website').value;
    const apiKey = document.getElementById('api-key').value;
    const balance = document.getElementById('balance').value;

    const tableBody = document.querySelector('#provider-table tbody');
    const newRow = document.createElement('tr');

    newRow.innerHTML = `
        <td>${name}</td>
        <td><a href="${website}" target="_blank">${website}</a></td>
        <td>${apiKey}</td>
        <td>${balance} $</td>
    `;

    tableBody.appendChild(newRow);
    
    // Сброс формы
    document.getElementById('provider-form').reset();
});
```

### Результат

Этот код создает веб-приложение с простым и современным дизайном в темных тонах. Пользователи могут вводить информацию о провайдерах и добавлять её в таблицу. При наведении на строки таблицы они становятся светлее. Код обеспечивает отзывчивый интерфейс, который будет хорошо выглядеть на различных устройствах.
