# Designer — Output

### CSS (style.css)

```css
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

body {
    font-family: 'Arial', sans-serif;
    background-color: #121212;
    color: #ffffff;
    line-height: 1.6;
    padding: 20px;
}

header {
    text-align: center;
    padding: 10px;
    margin-bottom: 20px;
}

h1 {
    font-size: 2em;
}

.provider-list {
    overflow-x: auto;
}

table {
    width: 100%;
    border-collapse: collapse;
}

th, td {
    padding: 15px;
    text-align: left;
    border-bottom: 1px solid #333;
}

th {
    background-color: #1e1e1e;
}

tr:hover {
    background-color: #2a2a2a;
    transition: background-color 0.3s ease;
}

input[type="text"],
input[type="number"] {
    width: calc(100% - 20px);
    padding: 10px;
    border: none;
    border-radius: 4px;
    background-color: #333;
    color: #fff;
    transition: background-color 0.3s ease;
}

input[type="text"]:focus,
input[type="number"]:focus {
    background-color: #444;
    outline: none;
}

a {
    color: #4caf50;
    text-decoration: none;
    transition: color 0.3s ease;
}

a:hover {
    color: #81c784;
}

footer {
    text-align: center;
    margin-top: 20px;
    font-size: 0.9em;
}
```

### Пояснение
1. **Тёмная тема**: Фон тела и фона таблицы тёмные, текст белый, а интерактивные элементы выделены зелёными оттенками, что создает контраст.
2. **Отзывчивая вёрстка**: Использование `overflow-x: auto;` для таблицы позволяет пользователю прокручивать длинные строки на устройствах с маленьким экраном.
3. **Анимации**: Добавлены эффекты наведения на строки таблицы и ссылки.
4. **Удобные поля ввода**: Поля ввода внешне оформлены с помощью стилей, создающих единую эстетическую линию.

Такое приложение будет выглядеть современно и приятно для глаз, а также работать на любых устройствах, благодаря отзывчивой вёрстке. Вы можете добавить JavaScript для большей функциональности, такой как отправка данных на сервер или валидация ввода.
