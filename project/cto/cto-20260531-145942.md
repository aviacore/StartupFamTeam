# Архитектура Web-приложения Крестики-нолики

## Технологический стек
- **Frontend**: HTML/CSS/JavaScript — используется для создания интерфейса игры.
- **Backend**: Node.js — обработка логики игры и управления ходами.
- **Database**: SQLite — для хранения данных об обучении ИИ (нетрудный в использовании и настройке).
- **Deployment**: GitHub Pages — размещение статического контента игры.

## Компоненты

1. **UI (Пользовательский интерфейс):**
   - HTML и CSS для рендеринга игрового поля 3x3.
   - JavaScript для обработки пользовательских действий и отображения сообщений о ходе игры.

2. **Бизнес-логика:**
   - Логика игры на стороне клиента (JavaScript): определения победителя, обработка ничьих, базовая логика хода ИИ.

3. **ИИ логику:**
   - Простое обучение на основе игр, данных сохраняемых в SQLite: игра анализирует прошлые игры и пытается улучшить свои действия на основе этого опыта.

4. **Серверная часть:**
   - Node.js для обработки более сложной логики и взаимодействие с базой данных.
   - Обеспечение взаимодействия клиента и сервера через REST API для сохранения и извлечения данных обучения.

## Хранение данных

Игровые данные из базы SQLite включают:
- **Результаты игр**: хранение исходов и выполненных ходов для тренировки ИИ.
- **Обучение ИИ**: использование данных об исходах игр для улучшения игрового процесса ИИ.

## Размещение

Используются GitHub Pages для размещения HTML/CSS/JS части приложения. Это обеспечивает легкий доступ к приложению и отсутствие необходимости собственного сервера для сторонизации статического контента.

## Сетевая архитектура

- **Frontend** взаимодействует с **Backend** посредством REST API.
- **Backend** управляет взаимодействием с базой данных SQLite и передает результат обратно в UI.

Итоговая архитектура предоставляет пользователю интуитивно понятный интерфейс для игры в "Крестики-нолики" и обеспечивает базовое обучение ИИ для улучшения игровых сессий.
