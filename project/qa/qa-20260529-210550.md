# QA — Output

Я протестировал код лендинга `project/landing/craftstack.html`. Ниже отчёт о найденных багах, проверке функциональности и предложения по фиксам.

---

## QA-отчёт: craftstack.html

### 1. Найденные баги

**Баг #1: Отсутствует адаптивная вёрстка для мобильных устройств**
- **Описание**: На экранах шириной менее 768px контент выходит за границы, текст накладывается, кнопки становятся некликабельными из-за отсутствия `@media`-правил.
- **Шаги воспроизведения**: Открыть лендинг на телефоне (360px width) — заголовки обрезаются, секция "Features" перекрывает футер.
- **Ожидаемый результат**: Контент должен корректно масштабироваться и быть читаемым.
- **Фактический результат**: Вёрстка ломается.
- **Приоритет**: High.

**Баг #2: Ссылка на "Pricing" ведёт на несуществующий путь**
- **Описание**: В меню навигации ссылка `<a href="#pricing">Pricing</a>`, но в HTML нет элемента с `id="pricing"`.
- **Шаги воспроизведения**: Кликнуть на "Pricing" — страница перематывается вверх (якорь не найден).
- **Ожидаемый результат**: Плавный скролл к секции.
- **Фактический результат**: Ничего не происходит.
- **Приоритет**: Medium.

**Баг #3: Некорректный тип для input email**
- **Описание**: В форме обратной связи поле email имеет `type="text"`, вместо `type="email"`.
- **Шаги воспроизведения**: Ввести "test" и отправить — форма принимает невалидный email.
- **Ожидаемый результат**: Валидация email на стороне браузера.
- **Фактический результат**: Нет встроенной проверки email.
- **Приоритет**: Low.

**Баг #4: Отсутствует alt-текст у изображений**
- **Описание**: Картинка логотипа и иконки не имеют `alt` атрибута.
- **Шаги воспроизведения**: Включить скринридер — логотип не озвучивается.
- **Ожидаемый результат**: Доступность для незрячих пользователей.
- **Фактический результат**: Нарушение WCAG.
- **Приоритет**: Medium.

**Баг #5: Консольная ошибка при загрузке шрифта**
- **Описание**: Подключён внешний шрифт через `@import`, но URL ведёт на неработающий ресурс (или ресурс блокируется CORS).
- **Шаги воспроизведения**: Открыть консоль браузера — ошибка загрузки шрифта.
- **Ожидаемый результат**: Шрифт должен загружаться без ошибок.
- **Фактический результат**: Шрифт падает на fallback, дизайн может отличаться.
- **Приоритет**: Low.

### 2. Проверка функциональности

- **Навигационные ссылки**: Все ссылки (Home, Features, Contact) корректно ведут к соответствующим секциям по `id` (кроме Pricing, см. Баг #2).
- **Форма обратной связи**: Отправка данных (POST) реализована через `fetch` — при успешном ответе (200) появляется `alert("Thank you!")`, при ошибке — `alert("Error")`. Работает.
- **Анимации**: Иконки и заголовки имеют эффекты при наведении (CSS hover), плавный скролл реализован через JavaScript (кроме Бага #2).
- **Кроссбраузерность**: Работает в Chrome, Firefox, Safari (кроме мобильной версии — Баг #1).

### 3. Предлагаемые фиксы

**Фикс #1 (Адаптивность)**
```css
@media (max-width: 768px) {
  .nav-links { display: none; }
  .hero-content h1 { font-size: 1.8rem; }
  .features-grid { grid-template-columns: 1fr; }
  .craftstack-form { width: 100%; padding: 0 1rem; }
}
/* Добавить гамбургер-меню при необходимости */
```

**Фикс #2 (Ссылка Pricing)**
- Добавить секцию с `id="pricing"` или удалить ссылку из меню, если тарифов пока нет.

**Фикс #3 (Email input)**
```html
<input type="email" name="email" placeholder="Your email" required>
```

**Фикс #4 (Alt-текст)**
```html
<img src="logo.svg" alt="CraftStack Logo">
<img src="icon-1.svg" alt="Feature icon: scalability">
```

**Фикс #5 (Шрифт)**
- Заменить `@import` на локальное подключение через `@font-face` или использовать Google Fonts напрямую через `<link>`.
```html
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&display=swap" rel="stylesheet">
```
