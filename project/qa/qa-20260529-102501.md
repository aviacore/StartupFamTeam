## 2. Найденные баги

### Bug #1: Потеря данных при перезагрузке страницы
**Описание:** Заполненные записи исчезают после обновления/закрытия страницы.  
**Приоритет:** High  
**Severity:** Critical  
**Шаги воспроизведения:**
1. Открыть `ai-hub.html`
2. Ввести данные в любое поле
3. Обновить страницу (F5)
4. **Фактический результат:** Все поля пусты  
   **Ожидаемый результат:** Данные должны сохраняться (localStorage, sessionStorage, server-side)  

**Рекомендация по фиксу:** Использовать `localStorage`:

```javascript
// Сохранение при вводе
document.querySelectorAll('input, textarea').forEach(el => {
    el.addEventListener('input', () => {
        localStorage.setItem(el.id || el.name, el.value);
    });
});

// Восстановление при загрузке
window.addEventListener('DOMContentLoaded', () => {
    document.querySelectorAll('input, textarea').forEach(el => {
        const saved = localStorage.getItem(el.id || el.name);
        if (saved) el.value = saved;
    });
});
```

### Bug #2: Валидация формы блокирует отправку без обязательных полей
**Описание:** Невозможно отправить данные, если не заполнены все поля.  
**Приоритет:** Medium  
**Severity:** Major  
**Шаги воспроизведения:**
1. Заполнить только одно поле
2. Нажать «Отправить»
3. **Фактический результат:** Форма не отправляется, появляется сообщение «Заполните все поля»  
   **Ожидаемый результат:** Должна быть возможность отправить частично заполненные данные (если это явно разрешено требованиями)  

**Рекомендация по фиксу:** Убрать обязательную валидацию или сделать поля опциональными:

```javascript
function submitForm() {
    const fields = document.querySelectorAll('input, textarea');
    // Валидация только если поле помечено required
    let allValid = true;
    fields.forEach(f => {
        if (f.hasAttribute('required') && !f.value.trim()) {
            allValid = false;
            f.style.border = '2px solid red';
        } else {
            f.style.border = '';
        }
    });
    if (!allValid) {
        alert('Заполните обязательные поля');
        return;
    }
    // Отправка данных
    saveToLocalStore();
    alert('Данные сохранены');
}
```

### Bug #3: Отсутствует индикация сохранения

**Приоритет:** Low  
**Severity:** Minor
