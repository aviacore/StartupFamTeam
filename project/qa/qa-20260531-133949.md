## 2. Функциональное тестирование (E2E)

### 2.1. Загрузка игры
- **Ожидание:** При открытии `game.html` отображается поле 3x3, кнопка «Новая игра» и индикатор хода.
- **Результат:** ✅ Ок — всё отображается. Поле пустое, крестики ходят первыми.

### 2.2. Ход игрока (человек)
- **Действие:** Клик по центральной ячейке (1,1).
- **Ожидание:** В ячейке появляется «X», ход переходит к ИИ.
- **Результат:** ✅ Ок — «X» отображается, ячейка блокируется.

### 2.3. Ход ИИ (противник)
- **Действие:** После хода игрока ждём 500 мс.
- **Ожидание:** ИИ ставит «O» в случайную/лучшую свободную клетку.
- **Результат:** ✅ Ок — «O» появляется в свободной клетке.

### 2.4. Проверка победы
- **Действие:** Играем до победы X (например, верхняя строка).
- **Ожидание:** Сообщение «X победил!», игра блокируется.
- **Результат:** ✅ Ок — победа определяется корректно.

### 2.5. Проверка ничьей
- **Действие:** Заполняем все клетки без победы.
- **Ожидание:** Сообщение «Ничья!», поле блокируется.
- **Результат:** ✅ Ок.

### 2.6. Кнопка «Новая игра»
- **Действие:** Нажать после завершения партии.
- **Ожидание:** Поле очищается, счёт обнуляется (опционально), ход переходит к X.
- **Результат:** ✅ Ок — поле пустое, игра начинается заново.

### 2.7. Самообучение (нейронка)
- **Действие:** Нажать кнопку «Обучить» (или автоматически после каждой игры).
- **Проверка:** В консоли браузера (F12) видно сообщение `[Training] Game finished — updating weights...`.

## 3. Найденные баги

### БАГ #1 (Critical)
- **Файл:** `project/tic-tac-toe.js` — функция `saveWeights()`
- **Проблема:** Веса нейронки не сохраняются в localStorage. После перезагрузки страницы self-play сбрасывается.
- **Ожидание:** При завершении игры веса должны записываться в `localStorage.setItem('ttt_weights', JSON.stringify(weights))`.
- **Реальность:** Функция есть, но не вызывается после игры.  
  **Фикс:** Вставить `this.saveWeights();` в метод `endGame()`.

### БАГ #2 (Minor)
- **Файл:** `project/tic-tac-toe.js` — строка 142
- **Проблема:** При ничьей нейронка не получает награду (reward = 0).  
- **Ожидание:** reward = 0.5 (нейтральный).  
- **Реальность:** Функция `learn()` не обрабатывает случай ничьей — выдаёт undefined или 0.  
  **Фикс:** Добавить условие `if (winner === 'draw') { reward = 0.5; }`.

### БАГ #3 (Info)
- **UI:** При очень быстром двойном клике на занятую клетку игра зависает на 1-2 секунды.  
- **Причина:** ИИ запускает повторный расчёт при клике на блокированную ячейку.  
- **Фикс:** В обработчике клика добавить `if (cell.textContent !== '') return;` (уже есть, но не проверяет состояние `gameOver`). Добавить `if (this.gameOver) return;`.
