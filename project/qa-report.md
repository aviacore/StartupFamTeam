# QA-отчёт — Пятнашки

| Проверка | Статус | Примечание |
|----------|--------|------------|
| Генерация поля 4×4 | ✅ OK | 15 фишек + пустая клетка |
| Перемешивание (Fisher-Yates) | ✅ OK | С проверкой решаемости |
| Клик по фишке → движение | ✅ OK | Только соседние с пустой |
| Счётчик ходов | ✅ OK | Инкремент при каждом move |
| Таймер | ✅ OK | Старт при новой игре, стоп при победе |

| LocalStorage рекордов | ✅ OK | Лучшее: ходы + время |
| Смена темы (тёмная/светлая) | ✅ OK | Toggle-кнопка |
| Адаптивная вёрстка | ✅ OK | Media queries для мобильных |
| Анимации | ✅ OK | CSS transitions + hover-эффекты |
| Цветные фишки | ✅ OK | Каждое число — свой градиент |
| Фоновые частицы | ✅ OK | Плавная анимация |

## Найденные баги
- 🐛 Нет проверки нажатия клавиш (только клик)
- 🐛 Нет подтверждения при начале новой игры (сбрасывает текущую)
- 🐛 При очень быстром двойном клике — фишка может не успеть анимироваться

## Рекомендации
1. Добавить клавиатурное управление (стрелки)
2. Подтверждение «Новой игры» если игра не завершена
3. Добавить анимацию перемешивания
4. Добавить звуки при move и победе

## Вердикт: ✅ MVP готов к запуску
Игра полностью рабочая, баги некритичные. Можно деплоить.
