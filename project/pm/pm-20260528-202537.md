# Задачи для разработки WEB-приложения (Task Breakdown)

## 1. Спроектировать и сверстать макет главной страницы (UI)

**Описание:**  
Разработать современный, минималистичный дизайн главной страницы. Дизайн должен включать:  
- Список провайдеров/моделей с карточками.  
- Поля для ввода API-ключа и остатка денег (персонально для каждого провайдера/модели).  
- Ссылки на официальные сайты провайдеров.  
- Адаптивность под мобильные устройства.  
Использовать современные CSS-фреймворки (Tailwind, Bootstrap или аналоги) или чистый CSS Grid/Flexbox.

**Критерии приёмки:**  
- Создан статический HTML-шаблон с не менее чем 5-ю популярными провайдерами (например, OpenAI GPT, Google Gemini, Anthropic Claude, Mistral AI, DeepSeek).  
- В карточке каждого провайдера: логотип, название модель (опционально), ссылка на сайт, поле ввода API-ключа и поле ввода остатка средств.  
- Дизайн соответствует современным трендам: светлые/тёмные тона, тени, скругления, адаптивная сетка.  

**Приоритет:** P0

## 2. Реализовать логику добавления/редактирования API-ключа и остатка денег

**Описание:**  
Создать функционал (JavaScript/React/Vue или чистый JS), который позволяет пользователю:  
- Вводить API-ключ для каждого провайдера (сохраняется в localStorage или sessionStorage).  
- Вводить/редактировать остаток денег (числовое поле, формат: 0.00).  
- Данные не отправляются на сервер, хранятся локально.  

**Критерии приёмки:**  
- После ввода ключа он отображается в “звёздочками” (маскирование), но при редактировании показывается обычным текстом.  
- Остаток денег сохраняется с точностью до двух знаков.  
- При перезагрузке страницы данные восстанавливаются.  

**Приоритет:** P0

## 3. Отобразить список популярных провайдеров/моделей с данными (статические данные)

**Описание:**  
Создать JSON или JS-объект со списком провайдеров (минимум 10):  
- название,  
- модель (если есть, например, GPT-4, Gemini Pro, Claude 3),  
- URL официального сайта,  
- описание (краткое, опционально).  
Использовать этот список для динамического рендера карточек.  

**Критерии приёмки:**  
- Список отображается на главной странице в виде сетки.  
- Каждая карточка содержит название, модель, ссылку на сайт.  
- Если у провайдера несколько моделей – каждая модель отображается отдельно (например, OpenAI: GPT-3.5, GPT-4).  

**Приоритет:** P1

## 4. Добавить интерактивный остаток денег (диаграмма или прогресс-бар)

**Описание:**  
Визуализировать остаток денег для каждого провайдера (например, круговая диаграмма или прогресс-бар с цветовой индикацией).  
- Если остаток > 50% – зелёный.  
- Если от 20% до 50% – жёлтый.  
- Если < 20% – красный.  
Предусмотреть возможность сброса остатка в ноль.  

**Критерии приёмки:**  
- На карточке отображается визуальный индикатор.  
- Цвет меняется в зависимости от введённого значения.  
- При клике на индикатор можно открыть поле для изменения суммы.  

**Приоритет:** P2

**Описание:**  
Добавить строку поиска, позволяющую фильтровать провайдеров по названию или модели.  
- Поиск работает по частичному совпадению (без учёта регистра).  
- Результаты обновляются в реальном времени при вводе.  

**Критерии приёмки:**  
- Поле поиска расположено в шапке страницы.  
- При вводе “gpt” отображаются только провайдеры, содержащие это слово.  
- Если ничего не найдено – сообщение “Провайдеры не найдены”.  

**Приоритет:** P1

## 6. Настроить локальное сохранение данных (localStorage)

**Описание:**  
Реализовать сохранение всех введённых пользователем данных (API-ключи, остатки) в localStorage браузера.  
- При первом запуске – пустые значения.  
- При каждом изменении – данные перезаписываются.  
- При загрузке страницы данные восстанавливаются.  

**Критерии приёмки:**  
- После ввода ключа/остатка и перезагрузки страницы данные сохраняются.  
- Очистка localStorage (кнопка “Сбросить всё”) удаляет все сохранённые данные.  

**Приоритет:** P0
