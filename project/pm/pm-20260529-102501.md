# Задачи: Доработка веб-приложения ai-hub.html

## Задача 1: Реализация сохранения записей в localStorage

- **Заголовок:** Сохранение записей в localStorage
- **Описание:** Необходимо добавить функциональность сохранения всех записей (текстовые сообщения, заметки, введенные данные) в localStorage браузера. При перезагрузке страницы записи должны автоматически загружаться из localStorage и отображаться. Данные должны сохраняться после каждого ввода или редактирования.
- **Критерии приёмки:**
  - Записи сохраняются в localStorage при каждом их добавлении или изменении.
  - При перезагрузке страницы все сохраненные записи отображаются корректно.
  - Сохраняется структура данных (дата, время, содержание, теги и т.д.).
  - Удаление отдельной записи приводит к обновлению localStorage (запись исчезает).
- **Приоритет:** P0

## Задача 2: Автоматическое восстановление состояния при загрузке страницы

- **Заголовок:** Восстановление состояния из localStorage при инициализации
- **Описание:** При загрузке страницы необходимо выполнять проверку наличия сохраненных данных в localStorage. Если данные существуют — они должны быть десериализованы и отображены в соответствующем разделе приложения. Если данных нет — показывать пустое состояние (приветственное сообщение или пустой список).
- **Критерии приёмки:**
  - При загрузке страницы вызывается функция `loadFromLocalStorage()`.
  - Если данные есть — они парсятся и отображаются.
  - Если данных нет — отображается пустой список или системное сообщение.
  - Никаких ошибок в консоли при загрузке.
- **Приоритет:** P1

## Задача 3: Возможность частичного заполнения данных (необязательные поля)

- **Заголовок:** Пометка полей как необязательных и разрешение отправки без полного заполнения
- **Описание:** Необходимо изменить логику формы ввода (окна заполнения), чтобы некоторые поля стали необязательными. Пользователь может отправить данные, даже если заполнены не все поля. Обязательными оставить только поля, без которых запись не имеет смысла (например, заголовок или краткое описание). Остальные поля (теги, расширенное описание, дата и т.д.) сделать опциональными.
- **Критерии приёмки:**
  - Определён список обязательных полей (минимум 1-2 поля).
  - Если все обязательные поля заполнены — кнопка отправки активна.
  - Если не заполнено ни одно обязательное поле — кнопка отправки неактивна или показывается предупреждение.
  - Незаполненные необязательные поля не вызывают ошибок при отправке.
  - При сохранении пустые поля либо не сохраняются, либо сохраняются как `null`/пустая строка без нарушения структуры.
- **Приоритет:** P0

## Задача 4: Валидация обязательных полей перед сохранением

- **Заголовок:** Валидация обязательных полей при отправке формы
- **Описание:** При нажатии на кнопку «Сохранить» или «Отправить» должна выполняться проверка заполнения обязательных полей. Если хотя бы одно обязательное поле пустое — показывать сообщение пользователю (например, подсказку или alert) и блокировать сохранение. Если валидация пройдена — сохранять запись в localStorage и обновлять UI.
- **Критерии приёмки:**
  - Проверка происходит перед записью в localStorage.
  - При пустом обязательном поле — запись не сохраняется, выводится сообщение об ошибке.
  - Сообщение об ошибке должно быть информативным (например, «Поле "Заголовок" обязательно для заполнения»).
  - После успешной валидации данные сохраняются, и форма очищается (или сбрасывается).
- **Приоритет:** P1

## Задача 5: Сброс полей (кнопка «Отмена» или «Очистить») без потери данных в памяти

- **Заголовок:** Кнопка сброса формы с очисткой полей, но без удаления сохранённых записей
- **Описание:** Добавить кнопку «Очистить» / «Отмена» рядом с кнопкой сохранения. При нажатии на неё все поля формы должны очиститься (сброситься в пустое состояние), но записи, уже сохранённые в localStorage, не должны удаляться или изменяться. Функция должна также закрывать/сворачивать окно заполнения (если это модальное окно).
- **Критерии приёмки:**
  - Кнопка «Очистить» видна и активна.
  - При нажатии поля формы становятся пустыми.
  - localStorage не изменяется.
  - UI возвращается в предыдущее состояние (без новой записи).
  - Если форма была в режиме редактирования, изменения отменяются.
- **Приоритет:** P2

## Задача 6: Юнит-тесты (или ручное тестирование) для проверки работы с памятью и частичного заполнения

- **Заголовок:** Написание тестов для проверки сохранения в localStorage и частичного заполнения
- **Описание:** Разработать набор простых ручных тестов (или автоматизированных с помощью console.assert) для проверки:
  1. Сохранение записи в localStorage.
  2. Загрузка записей из localStorage при старте.
  3. Валидация обязательных полей.
  4. Возможность сохранения с неполными данными (если необязательные поля пусты).
  5. Удаление записи из localStorage.
  6. Сброс формы без удаления данных.
- **Критерии приёмки:**
  - Каждый тест выполняется без ошибок.
  - В случае автоматических тестов — наличие вызовов `console.assert` или `try/catch` с выводом результата.
  - Тесты можно запустить в браузерной консоли после загрузки страницы.
- **Приоритет:** P3
