### Рекламный проспект: CraftStack — Эволюция управления проектами

**Слоган: *CraftStack: Умный PM. Больше чем Paperclip.***

#### Страница 1: Проблема и Решение

**(Визуал: Слева — запутанный клубок проводов (Paperclip), справа — аккуратные, разноцветные блоки (CraftStack).)**

**Paperclip** — это прошлый век. Он решал задачу, когда проекты были линейными, а команды — маленькими. Но сегодняшний мир требует скорости, гибкости и прозрачности.

**CraftStack** — это платформа, которая не просто «ведёт задачи», а управляет *процессом*. Мы объединили лучшее из лучших практик и добавили ИИ-ассистента.

#### Страница 2: Сравнение "Лоб в лоб"

**(Визуал: Таблица с цветной индикацией: зелёный (CraftStack) vs серый (Paperclip))**

| Критерий | Paperclip | CraftStack | **Преимущество** |
| :--- | :--- | :--- | :--- |
| **Декомпозиция задач** | Только вручную | Авто-декомпозиция + ИИ | **CraftStack быстрее в 3x** |
| **Sprint Planning** | Бумажный шаблон | Drag-and-drop + Балансировка нагрузки | **CraftStack (живой)** |
| **Требования (Spec)** | Markdown / Google Docs | Встроенная Wiki + Диаграммы | **CraftStack (всё в одном)** |
| **Приоритеты** | Метки (P0-P3) | Те же метки + Авто-сортировка по рискам | **CraftStack (умный)** |
| **Отчетность** | Статические таблицы | Динамические графики Burndown / Velocity | **CraftStack (аналитика 24/7)** |
| **Интеграции** | Почта + календарь | GitHub, GitLab, Jira, Slack, Telegram | **CraftStack (хаб)** |

#### Страница 3: Графика "Скорость работы"

**(Визуал: Гистограмма. Ось Y: Затраченное время на создание Sprint Backlog. Ось X: Количество задач.)**

*   **Синий столбец (Paperclip):** Растёт экспоненциально.
    *   *Текст:* «Каждая новая задача требует ручного согласования Spec и приоритета».
*   **Зелёный столбец (CraftStack):** Почти прямая линия.
    *   *Текст:* «ИИ автоматически подгружает шаблоны из истории и предлагает готовые Acceptance Criteria».

**Вывод:** CraftStack **экономит до 40% времени** на этапе планирования каждого спринта.

#### Страница 4: Диаграмма "Прозрачность"

**(Визуал: Круговая диаграмма (Pie Chart) для каждого проекта)**

*   **Paperclip:** «Чёрный ящик». Менеджер узнаёт о проблеме в конце спринта.
    *   *Данные:* 70% времени уходит на статус-митинги, 30% — на реальную работу.
*   **CraftStack:** «Живой дашборд».
    *   *Данные:* 95% времени — реальная работа, 5% — контроль через встроенный Burndown chart и Health-метрики команды.

**Сообщение:** CraftStack даёт **реальную картину здоровья проекта** без лишних совещаний.

#### Страница 5: Призыв к действию

**(Визуал: Сплит-экран: "CraftStack" (кнопка "Начать") и "Paperclip" (кнопка "Остаться в прошлом"))**

**Текст:**
*   **Paperclip** — это средство для записи.
*   **CraftStack** — это инструмент для создания.

**Почему стоит перейти?**
*   **Быстрее:** Автоматическая генерация Task Breakdown.
*   **Чётче:** Живые требования (Live Spec).
*   **Умнее:** Приоритеты, основанные на данных, а не на интуиции.
