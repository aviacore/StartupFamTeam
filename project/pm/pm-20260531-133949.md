**Описание:**
Спроектировать структуру игры "Крестики-нолики" с модулем нейросети. Разработать файловую структуру проекта, определить компоненты: игровое поле, ИИ-агент, модуль обучения, UI. Создать файл `project/tictactoe/arch.md` с описанием архитектуры.

**Критерии приёмки:**
- Определены 4 основных модуля: game (логика игры), ai (нейросеть), ui (интерфейс), storage (сохранение данных)
- Описана файловая структура: `project/tictactoe/` с подпапками
- Указаны зависимости: только stdlib Python, HTML/CSS/JS без фреймворков
- Документ сохранён в `project/tictactoe/arch.md`

**Приоритет:** P0

## Задача 2: Реализовать игровую логику (P0)

**Описание:**
Написать модуль игры `project/tictactoe/game.py` с классами: `Board` (доска 3x3), `Game` (управление ходами), `Player` (человек/ИИ). Реализовать проверку победителя, ничьей, валидацию ходов. Поддержать два режима: человек vs человек, человек vs ИИ.

**Критерии приёмки:**
- `Board` хранит состояние 3x3 (0 - пусто, 1 - крестик, 2 - нолик)
- `Game` управляет очередностью ходов, проверяет победу/ничью
- Функция `check_winner(board)` возвращает победителя или None
- Поддержка обоих режимов через параметр `mode`
- Юнит-тесты для всех сценариев (победа по вертикали/горизонтали/диагонали, ничья)

**Приоритет:** P0

## Задача 3: Разработать ИИ-агент с нейросетью (P0)

**Описание:**
Создать модуль `project/tictactoe/ai.py` с классом `NeuralNetwork` — минимальная нейросеть (однослойный перцептрон или простейшая полносвязная сеть). Реализовать обучение методом самоигры (self-play): ИИ играет сам с собой, обновляет веса на основе результатов. Размер сети: вход 9 нейронов (состояние доски), скрытый слой 9-27 нейронов, выход 9 нейронов (вероятности ходов).

**Критерии приёмки:**
- Архитектура сети: вход(9) → скрытый(9-27, ReLU) → выход(9, softmax)
- Обучение через backpropagation (градиентный спуск)
- Функция `train(epochs=1000)` запускает самоигру
- Функция `predict(board)` возвращает массив вероятностей ходов
- Веса сохраняются в `project/tictactoe/weights.json`
- Обучение проходит за <30 секунд на CPU (1000 эпох)

**Приоритет:** P0

## Задача 5: Интегрировать с сервером CraftStack (P1)

**Описание:**
Дополнить `server.py` роутами для игры: `/api/game/state` — текущее состояние игры, `/api/game/move` — ход игрока, `/api/game/reset` — сброс. Настроить SSE на обновления. Игра работает как отдельный сервис на порту 8766 или как подпуть на 8765.

**Критерии приёмки:**
- GET `/api/game/state` возвращает JSON с доской, очередью, счётом
- POST `/api/game/move` принимает `{x, y}` и возвращает обновлённое состояние
- POST `/api/game/reset` сбрасывает игру
- SSE отправляет обновления при ходе ИИ
- Обработка ошибок (невалидный ход, игра завершена)

**Приоритет:** P1
