**Заголовок:** Реализовать сохранение данных в localStorage

**Критерии приемки:**  
- После добавления/удаления/редактирования данные сохраняются  
- После перезагрузки страницы данные восстановлены  
- API-ключи не отображаются в открытом виде в localStorage  

**Приоритет:** P2
