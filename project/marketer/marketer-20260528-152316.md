# Marketer — Output

Отлично! Я — **Marketer**. Проанализировав работу CEO, PM, CTO, Developer и Designer, я вижу, что у нас есть:
- **Бэкенд** (API, JSON, скрипты) — от CTO и Developer.
- **Фронтенд** (стильный дашборд) — от Designer.
- **Процессы** (таски, спринты, документация) — от PM.

Но **продукт не имеет лица для внешнего мира**. Нет лендинга, нет питча, нет упаковки для инвесторов/клиентов. Моя задача — превратить внутреннюю техническую разработку в привлекательный, продающий продукт, который можно показать публике.

## Вклад Marketer: Упаковка, воронка и контент

### 1. Целевая аудитория (ЦА)

Я не могу создать хороший лендинг, не понимая, кому мы продаём. На основе анализа проекта выделяю 3 сегмента:

| Сегмент | Боли / Потребности | Как наш продукт помогает |
|---------|-------------------|--------------------------|
| **CEO стартапов** | Хаос в команде, не понимают, кто за что отвечает на русском языке. Нет единого глоссария. | Даёт прозрачную карту ролей (Plan_06), автоматизирует сбор названий, экономит 3+ часа ручной работы в неделю. |
| **Продуктовые команды (PM + Dev)** | Путаница в терминологии между англ. скиллами и русскими названиями. Долгие созвоны для согласования. | API + дашборд — всё в одном месте. Мгновенная генерация актуального Plan_06.md. Минимизация ошибок. |
| **Инвесторы / Акселераторы** | Хотят видеть, что команда использует системный подход. Нужна чёткая питч-презентация. | Pitch Deck с описанием product-market fit, архитектуры и road map. |

### 3. Питч-презентация (`pitch.md`)

Создаю готовый текст для инвестора / CEO:

```markdown
# Pitch Deck: Plan_06 — AI-агент по управлению ролями команды

## Проблема
- В кросс-функциональных командах (CEO, PM, Dev, Design) хаос в названиях ролей.
- Сотрудники тратят 2–3 часа в неделю на согласование терминов.
- Нет единого источника правды (single source of truth).

## Решение
**Plan_06** — система из 4 AI-агентов, которые:
1. **Собирают** названия ролей (CEO запрашивает у каждого агента).
2. **Структурируют** в JSON (CTO) и визуализируют (Designer).
3. **Генерируют** отчёт Plan_06.md за 1 клик.
4. **Масштабируются** через API (Dev) для новых участников.

## Целевая аудитория
- CEO стартапов (первые 1000 пользователей — из Product Hunt).
- PM в IT-компаниях (1500+ команд в РФ).
- Акселераторы (партнёрство с 5+ программами).

## Конкурентное преимущество
- **Скорость:** генерация отчёта за 0.5 сек против 2 дней ручной работы.
- **Точность:** JSON-схема гарантирует отсутствие ошибок.
- **Эстетика:** дизайн-система Designer (тёмная тема, анимации) — продуктом приятно пользоваться.

## Бизнес-модель
- **Free:** базовый отчёт Plan_06 (до 4 агентов).
- **Pro ($9/мес):** неограниченное число агентов, кастомные поля, экспорт в PDF.
- **Enterprise:** API-доступ, SLA, интеграция с Jira/Notion.

## Road Map
- **Q2 2025:** Запуск лендинга + MVP (текущая версия).
- **Q3 2025:** Интеграция с Jira, добавление агента «Growth».
- **Q4 2025:** Мобильное приложение для CEO.

## Команда
- **CEO** — лидер, сбор требований.
- **PM** — стратегия и спринты.
- **CTO** — архитектура и API.
- **Dev** — код и тесты.
- **Designer** — UI/UX.
- **Marketer (я)** — упаковка и воронка.

**Контакты:** [ваш email]

```
