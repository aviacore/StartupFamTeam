```markdown
# Plan_04.md — Список ИИ-агентов для маркетинга

Для построения эффективной маркетинговой системы на базе ИИ-агентов предлагается следующий набор агентов, сгруппированных по функциональным блокам.

## 1. Исследование и аналитика
- **Агент-аналитик рынка** — сбор и анализ рыночных данных, трендов, конкурентов.
- **Агент-исследователь ЦА** — сегментация аудитории, портреты клиентов, поиск инсайтов.
- **Агент-мониторинг упоминаний** — отслеживание бренда, продуктов и ключевых слов в соцсетях и СМИ.

## 2. Контент и креатив
- **Агент-копайтер** — генерация текстов для лендингов, статей, email-рассылок, постов.
- **Агент-дизайнер** — создание визуалов (баннеры, обложки, инфографика) на основе брифов.
- **Агент-видеопродюсер** — генерация сценариев, раскадровок и коротких видео.

## 3. Запуск и привлечение трафика
- **Агент-таргетолог** — настройка и оптимизация рекламных кампаний (Яндекс.Директ, VK, Telegram Ads).
- **Агент-SEO** — анализ запросов, оптимизация контента, генерация мета-тегов.
- **Агент-коллтрекинг/чаты** — управление входящими заявками, первичная квалификация лидов.

## 4. Воронки и ретеншн
- **Агент-Lead Magnet** — создание полезных материалов (чек-листы, гайды, вебинары) для сбора контактов.
- **Агент-email маркетолог** — сегментация базы, написание писем, A/B-тесты.
- **Агент-ретеншен** — триггерные сценарии по возврату потерянных клиентов.

## 5. Контроль и отчётность
- **Агент-метрик** — сбор и визуализация ключевых KPI (лиды, CAC, LTV, ROMI).
- **Агент-гипотезовщик** — генерация маркетинговых гипотез на основе данных.
- **Агент-командир (оркестратор)** — управление очередью и передачей задач между агентами.

---

### Принцип развёртывания
Первые MVP-агенты (для лендинга и питча): **Агент-копайтер**, **Агент-дизайнер**, **Агент-таргетолог**. Остальные добавляются по мере роста проекта.

Файл сохранён: `project/Plan_04.md`
```
