# Plan_02.md

## План UI/UX для дашборда

### 1. Общая концепция
Дашборд предназначен для мониторинга ключевых показателей эффективности (KPI) маркетинговой кампании. Целевая аудитория — маркетологи и владельцы бизнеса, которым нужна быстрая и наглядная аналитика.

**Ключевая метрика:** Время до первого понимания данных — не более 5 секунд.

### 2. Структура (Размещение на рабочем столе)

*Файл будет находиться на рабочем столе, поэтому интерфейс должен быть лаконичным и не перегруженным.*

**Макет:**
| Header (Логотип / Название кампании) |
|--------------------------------------|
| **Строка фильтров** (Дата, Канал, Продукт)|
| KPI 1 | KPI 2 | KPI 3 | KPI 4 |
| (Карточка) | (Карточка) | (Карточка) | (Карточка) |
|-----------------|-----------------|
| **График 1** (Линейный: Трафик/Конверсии) | **График 2** (Круговая: Источники трафика) |
|-----------------|-----------------|
| **Таблица** (Топ-10 лидов / Расходы по каналам) |

### 3. UI-элементы (Детали)

*   **Цветовая схема:**
    *   Фон: Белый (#FFFFFF) / Светло-серый (#F5F7FA)
    *   Акцент: Синий (#0088FF) — для графиков и CTA (Call to Action)
    *   Успех: Зеленый (#0AC97F)
    *   Предупреждение: Оранжевый (#F38B00)
*   **Типографика:**
    *   Заголовки: Inter, Bold, 24px
    *   Показатели: Inter, SemiBold, 48px
    *   Текст: Inter, Regular, 14px
*   **Таблица:**
    *   Интерактивная сортировка по столбцам (клик по заголовку).
    *   Выделение строки при наведении.
    *   Пагинация (10 строк на страницу).
*   **Графики:**
    *   Использовать библиотеку Chart.js или D3.js для анимации.
    *   Инструменты подсказки (tooltips) при наведении на точки/сектора.
*   **Фильтры:**
    *   Дата: Календарь с предустановленными периодами (Сегодня, Неделя, Месяц).
    *   Чекбоксы для каналов.

### 4. UX-сценарии

1.  **Загрузка:** Скелетон (skeleton) загрузки — серые блоки мерцают, пока данные не подгрузятся.
2.  **Взаимодействие с фильтрами:** При изменении фильтра все блоки (KPI, графики, таблица) асинхронно перерисовываются. Пока данные загружаются, старые данные остаются на месте (чтобы не было пустоты).
3.  **Экспорт:** В правом верхнем углу каждой карточки графика кнопка "↓ Скачать PNG".
4.  **Ошибка:** Если данные не загрузились, показывать красный баннер с текстом "Ошибка загрузки данных. Попробуйте позже." и кнопку "Обновить".

### 5. Технические требования
*   **Фреймворк:** React + TypeScript (для SPA-подобного поведения).
*   **Адаптивность:** Минимальная ширина для комфортной работы — 1280px. При меньшем разрешении плейсхолдер: "Откройте на большом экране".
*   **Стейт-менеджмент:** Zustand (легковесный), чтобы избежать перерендера всех компонентов при изменении фильтра.
