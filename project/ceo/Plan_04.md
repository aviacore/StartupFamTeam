# План 04: Список ИИ-агентов для маркетинга

## 1. Контекст и цель
Для построения автономной маркетинговой системы требуется набор специализированных ИИ-агентов. Каждый агент выполняет конкретную функцию, взаимодействуя с другими через единую базу знаний/CRM. Ниже приведен минимально необходимый набор.

## 2. Перечень ИИ-агентов

### 2.1. Агент аналитики (Insight Agent)
**Задача:** Сбор и обработка рыночных данных, анализ конкурентов, выявление трендов и аудиторных сегментов.  
**Вход:** API соцсетей, новостные RSS, Google Trends, данные из CRM.  
**Выход:** Отчеты с инсайтами и рекомендации по позиционированию.

### 2.2. Агент контента (Content Agent)
**Задача:** Генерация текстов, изображений и видео для всех каналов — от постов в соцсетях до лендингов и email-рассылок.  
**Вход:** Брифы от стратега, стилистические гайды, SEO-ключи.  
**Выход:** Готовый контент в форматах .md, .png, .mp4 (или ссылки на размещение).

### 2.3. Агент стратегии (Strategy Agent)
**Задача:** Планирование кампаний, распределение бюджета, выбор каналов (Performance, Inbound, ABM). Корректировка плана по KPI.  
**Вход:** Бюджет, цели (CPA, ROI, охват), данные от аналитика.  
**Выход:** Медиаплан, сценарии A/B тестов, триггеры для запуска/остановки кампаний.

### 2.4. Агент коммуникации (Outreach Agent)
**Задача:** Автоматизация исходящих контактов: email-рассылки, cold outreach в LinkedIn, мессенджеры, чат-боты на сайте. Персонализация по поведению.  
**Вход:** Списки лидов, шаблоны писем, правила сегментации.  
**Выход:** Отправленные сообщения, логи ответов, квалифицированные лиды.

### 2.5. Агент рекламы (Ad Agent)
**Задача:** Управление платным трафиком: создание и оптимизация объявлений (Яндекс.Директ, Google Ads, VK Ads, TG Ads), ставки, таргетинг.  
**Вход:** Креативы от контент-агента, бюджет, настройки каналов.  
**Выход:** Аналитика по кампаниям, скриншоты статистики, рекомендации по масштабированию.

### 2.6. Агент лояльности (Retention Agent)
**Задача:** Удержание клиентов: триггерные письма, программы лояльности, опросы NPS, реактивация «спящих».  
**Вход:** История покупок, поведенческие события, статусы в CRM.  
**Выход:** Сценарии автоворонок, персональные предложения, отчеты по LTV.

## 3. Файл конфигурации
Список агентов сохраняется в файл `project/Plan_04.md`.
