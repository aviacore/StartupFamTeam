```markdown
# Бизнес-план: Tic-Tac-Toe AI

**Статус:** Утверждён (CEO)
**Версия:** 1.0
**Дата:** 2025-05-28

---

## 1. Executive Summary (Идея)

Разработка web-приложения «Крестики-нолики» (Tic-Tac-Toe) с интегрированной мини-нейронной сетью, которая обучается в реальном времени, играя против пользователя. Приложение имеет современный, минималистичный дизайн и служит демонстрацией возможностей CraftStack как платформы для быстрого прототипирования AI-продуктов.

## 2. Business Model (Бизнес-модель)

*   **Целевая аудитория:**
    *   Ретрогеймеры и casual-пользователи.
    *   Студенты и разработчики, интересующиеся AI/ML.
    *   Потенциальные клиенты CraftStack (как proof-of-concept).
*   **Продукт:** Бесплатное web-приложение с открытым исходным кодом.
*   **Монетизация (на данном этапе):** Отсутствует. Цель — создание портфолио-проекта и привлечение внимания к основной платформе (CraftStack).
*   **Ключевая метрика успеха (KPI):** Количество сыгранных партий, среднее время сессии, скорость обучения нейросети (количество ошибок на 100 партий).

## 3. Strategy (Стратегия реализации)

*   **Фаза 1 (MVP):**
    *   Игра «Человек против AI».
    *   Мини-нейронная сеть (перцептрон) на JavaScript, обучаемая методом Temporal Difference (TD) Learning.
    *   Минималистичный UI (HTML/CSS/JS) в современном стиле (material design / glassmorphism).
    *   Хранение весов нейросети в `localStorage`.
*   **Фаза 2 (Улучшение):**
    *   Режимы: «AI против AI» (ускоренное обучение), «Человек против человека».
    *   Визуализация процесса обучения (график ошибок, «тепловая карта» ходов).
    *   Сохранение статистики игр.
*   **Фаза 3 (Интеграция в CraftStack):**
    *   Размещение приложения в `project/` как одного из демо-артефактов.
    *   Создание страницы с описанием архитектуры и кода.

## 4. Features (Функциональные требования)

### MVP (Фаза 1)
1.  **Поле 3x3:** Кликабельные ячейки.
2.  **AI-игрок:**
    *   Мини-нейронная сеть (вход: 9 нейронов (состояние поля), скрытый слой: 9 нейронов, выход: 9 нейронов (вероятность хода)).
    *   Обучение: Temporal Difference (TD) Learning (метод, используемый в TD-Gammon).
    *   Алгоритм выбора хода: softmax выбор на основе выходных значений нейросети.
3.  **UI:**
    *   Современный дизайн (тёмная тема, анимации, градиенты).
    *   Индикатор хода.
    *   Счётчик побед/поражений/ничьих.
    *   Кнопка «Новая игра».
    *   Ползунок «Дерзость AI» (exploration vs exploitation) — регулирует температуру softmax.

### Будущие версии (Фаза 2+)
4.  **Режим AI vs AI.**
5.  **Режим 2 игрока.**
6.  **Визуализация обучения.**
7.  **Сброс нейросети до заводских настроек.**

## 5. Tech Stack (Технологический стек)

*   **Backend:** Отсутствует. Чистый Frontend.
*   **Frontend:**
    *   **HTML5/CSS3:** Современный дизайн, адаптивность.
    *   **Vanilla JavaScript (ES6):** Логика игры, нейронная сеть, обучение, UI.
*   **AI:** Мини-нейронная сеть на JavaScript (Matrix operations, sigmoid/softmax, Backpropagation).
*   **Хранение:** `localStorage` для весов нейросети и статистики.
*   **Инструменты разработки:** Текстовый редактор, CraftStack для управления задачами.

## 6. Architecture (Архитектура)

*   **index.html:** Основной файл приложения.
*   **js/app.js:** Основной скрипт: инициализация, обработка событий, игровой цикл.
*   **js/game.js:** Логика игры (проверка победителя, ходы, правила).
*   **js/neuralNetwork.js:** Класс `NeuralNetwork` с методами `forward()`, `train()`, `saveWeights()`, `loadWeights()`.
*   **js/ui.js:** Управление DOM, обновление счётчика, анимации.
*   **styles/style.css:** Основные стили.

**Данные (state):**
*   `board`: Array(9) (`null`, 'X', 'O').
*   `currentPlayer`: 'human' | 'ai'.
*   `winner`: 'X' | 'O' | 'draw' | null.
*   `history`: Array (состояния игры для обучения).
*   `score`: { wins: 0, losses: 0, draws: 0 }.

## 7. Timeline (Дорожная карта)

*   День 1: Создание структуры файлов, базовый UI (поле, стили), логика игры.
*   День 2: Разработка класса `NeuralNetwork` (forward pass, softmax).
*   День 3: Интеграция AI с игрой, реализация базового обучения (TD-Learning).
*   День 4: Тестирование, отладка, добавление ползунка «Дерзость AI», сохранение весов.
*   День 5: Косметические доработки, документирование.

## 8. Risks & Mitigation (Риски)

| Риск | Вероятность | Влияние | Стратегия смягчения |
|---|---|---|---|
| Нейросеть не обучается (застревает в локальном минимуме) | Низкая | Среднее | Использование TD-Learning вместо простого backprop; добавление exploration (softmax temperature). |
| Производительность на слабом CPU (Core m7) | Низкая | Низкое | Простая архитектура (9x9x9). JavaScript V8 справится. |
| Визуализация обучения сильно усложняет код | Средняя | Низкое | Перенести визуализацию на Фазу 2. |
| Не хватает времени (дедлайн) | Средняя | Среднее | Сфокусироваться на MVP. Отложить AI vs AI. |

---

**Решение CEO:** План утверждён. Начинаем разработку MVP. Приоритет — работающая нейросеть и минималистичный дизайн.
```
