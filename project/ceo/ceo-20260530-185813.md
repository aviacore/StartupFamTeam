# Business Plan for CraftStack

## 1. Введение

CraftStack – это легкий рабочий инструмент для AI-агентов, использующий модели OpenCode и прямые API для управления задачами от идеи до результата. Наш основной пользователь – это CEO и основатели стартапов, говорящие на русском языке.

## 2. Цели

Создание эффективной платформы для управления задачами с помощью AI-агентов, которая:
- Обеспечивает быструю и легкую работу без необходимости в тяжелых инструментах, таких как Paperclip.
- Позволяет пользователям легко управлять проектами, задачами и процессами в рамках бизнеса.

## 3. Ключевые решения

- Использование DeepSeek V4 Flash в качестве основной модели.
- Отказ от тяжелых решений, таких как Paperclip и Ollama.
- Применение файловой системы вместо базы данных для простоты и портативности.
- Использование SSE для обновления состояния в реальном времени.

## 4. Сравнение с Paperclip

| Параметр                  | CraftStack                                      | Paperclip                             |
|---------------------------|------------------------------------------------|--------------------------------------|
| Технические требования     | Легкий, подходит для CPU-only оборудования     | Тяжелый, требует больше ресурсов     |
| Время ответа              | Мгновенно, благодаря оптимизации работы с файлами | Задержки при использовании API и контекста |
| Пользовательский интерфейс  | Современный веб-dashboard с SSE-обновлениями  | Старый интерфейс, менее интуитивный |
| Адаптивность              | Настраиваемый под конкретные задачи             | Менее гибкий                          |

## 5. Описание функциональности

CraftStack предлагает 8 режимов работы, включая:
- CEO: Стратегия и бизнес-модели.
- PM: Управление задачами и спринтами.
- CTO: Архитектура и технологический стек.
- Developer: Написание кода и исправление ошибок.
- Designer: Проектирование графического интерфейса.
- Marketer: Рекламные материалы.
- QA: Тестирование и отчеты о качестве.
- Analyst: Анализ данных и исследования.

## 6. Техническая архитектура

Платформа работает на простом стеке технологий Python, используя HTTP-сервер (ThreadingHTTPServer) и REST API для управления задачами. Все данные сохраняются в локальной файловой системе в формате JSON.

## 7. Выводы

CraftStack предлагает более быстрый, легкий и удобный способ управления проектами по сравнению с Paperclip. Наше решение подходит для пользователей, которым нужна эффективность без лишних затрат на ресурсы и сложности в управлении.
