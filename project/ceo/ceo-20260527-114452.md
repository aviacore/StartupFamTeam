# Business Plan: «AI Mentor Pro»

## 1. Идея (Ideation)

**Проблема:**  
Менеджеры тратят 70% времени на рутину (отчеты, контроль KPI) и не успевают развивать софт-скиллы команды. Обучение продажам и управлению — дорогое и неэффективное (эффект забывания — 80% через неделю).

**Решение:**  
Платформа, где менеджер ежедневно тренируется на ИИ-симуляторах (сложный клиент, негативная обратная связь, переговоры). ИИ адаптируется под уровень пользователя и реальные кейсы компании.

**Ключевая инновация:**  
- **Hyper-realistic AI roleplay** — голосовой/текстовый ИИ, который имитирует клиентов/сотрудников с разными характерами.  
- **Мгновенная аналитика** — после сессии ИИ выдает метрики: эмпатия, аргументация, скорость реакции, эмоциональная стабильность.

## 2. Стратегия (Strategy)

### 2.1. Цель
За 12 месяцев: 100 B2B-клиентов (средний чек $15 000/год), ARR 1.5 М. Запуск через автоматизированный onboarding без менеджеров.

### 2.2. Этапы
1. **MVP (мес. 1–3):** Текстовая симуляция для менеджеров по продажам.  
2. **Alpha (мес. 4–6):** Голосовой UI + интеграция с CRM (Salesforce, HubSpot).  
3. **Beta (мес. 7–9):** Аналитика для HR-департамента + экспорт отчетов.  
4. **Scale (мес. 10–12):** API для кастомных сценариев, white-label для корпораций.

### 2.3. Конкуренция
- **Прямые конкуренты:** SecondNature, SalesScreen (игровые платформы).  
- **Отличие:** AI Mentor Pro учит не скриптам, а **адаптивному мышлению** (реагировать на непредвиденное).  
- **Барьер входа:** Собственный fine-tuned LLM-движок для диалогов (патент pending).

## 3. Бизнес-модель (Business Model)

### Revenue Streams
| Уровень | Цена | Включено |
|--------|------|----------|
| Start (до 10 юзеров) | $999/мес | 3 сценария, базовая аналитика |
| Pro (до 50 юзеров) | $2 500/мес | 20 сценариев, API, интеграция |
| Enterprise (unlimited) | $10 000/мес | White-label, выделенный сервер, кастомный ИИ |

### Unit Economics
- **CAC (привлечение):** $2 000 (контент-маркетинг + холодные письма)  
- **LTV (3 года):** $150 000 (Retention 95% при качественном контенте)  
- **Gross Margin:** 78% (основные затраты — GPU-облако $0.5/сессия)

### Metrics
- **Ключевой KPI:** DAU на аккаунт — >40% (норма для EdTech — 15%). Достигается микро-тренировками по 5 минут.  
- **Magic number:** Время «в формате» (training time) сотрудника >4 часов/месяц — это увеличивает NPS клиента на 20 пунктов.

## 4. Питч (Pitch)

### Elevator Pitch (30 сек)  
«Вы теряете $30K на каждом менеджере, который не умеет вести переговоры. AI Mentor Pro — первая симуляция, где ИИ играет роль *реального* оппонента: грубого, эмоционального, сомневающегося. Ваши менеджеры получают 20 лет опыта за 20 часов тренировок. Без ролей, без скриптов — только живая практика. Уже через месяц вы видите рост конверсии на 12%».

### Pitch Deck (3 слайда)  
1. **Слайд 1 (Проблема):** График «Стоимость ошибки менеджера» (упущенная сделка, уход сотрудника).  
2. **Слайд 2 (Решение):** Скриншот: чат с ИИ-клиентом, справа — шкала «Уровень убеждения» (0–100%).  
3. **Слайд 3 (Traction):** Цитата из пилота (розничная сеть): «Через 2 недели средний чек вырос на 8%».

## 5. Риски и Митигация

| Риск | Решение |
|------|--------|
| ИИ галлюцинирует, даёт вредные советы | Фильтр: все рекомендации перед показом проходят через контрольный LLM + human review |
