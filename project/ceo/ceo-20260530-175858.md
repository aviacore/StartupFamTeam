#### **Страница 2: "The Problem & The Solution"**

**Левая колонка (До):**
*   **Иконка:** Бумажный самолетик (Paperclip).
*   **Заголовок:** The Old Way (Paperclip)
*   **Текст:**
    *   "Paperclip is a great legacy solution — for 2010. It's a monolithic file attachment system, solving only the storage layer."
    *   **Проблемы:**
        *   Dependency hell (Gem conflicts).
        *   File validation is manual (regex + if-else).
        *   Zero context. It stores bytes, not data.
        *   Scaling requires 3rd party cloud re-writes (S3 + preloading).

**Правая колонка (После):**
*   **Иконка:** Светящийся бриллиант/шестигранник (CraftStack).
*   **Заголовок:** The New Stack (CraftStack)
*   **Текст:**
    *   "CraftStack is a microservice orchestration layer on steroids. It handles pipelines, ML pre-processing, and multi-cloud storage."
    *   **Решение:**
        *   **Module CORE:** AI-driven file categorization (Auto-tagging via LLM).
        *   **Module STREAM:** Real-time encoding and chunking for large files.
        *   **Module BRIDGE:** Native connection to S3, GCloud, or local SSD with 0 config.

---

#### **Страница 3: "Head-to-Head: The Comparison"**

**Визуал:** Табличное сравнение (заголовок колонки слева: Feature, далее CraftStack, затем Paperclip).

| **Feature / Metric** | **CraftStack (v3.2)** | **Paperclip (v6.x)** |
| :--- | :--- | :--- |
| **Architecture** | Event-driven, GraphQL API | Rails-specific, REST-only |
| **File Processing** | Async pipeline with Workers | Sync, blocks request thread |
| **AI/ML Integration** | Native (TensorFlow Lite / LLM) | No (requires monkey-patch) |
| **Storage Strategy** | Hybrid (hot + cold tiering) | Single filesystem path |
| **Setup Time** | 15 min (Docker Compose) | 30 min (Gem + Migrations + config) |
| **Scalability** | Horizontal (built-in sharding) | Vertical (need 3rd party) |
| **License** | MIT + Enterprise Add-ons | MIT (stale, no updates 2021) |

**Ключевая метрика (график "скорость обработки"):**
*   **График:** Столбчатая диаграмма (Ось X: Размер файла 1MB, 100MB, 1GB; Ось Y: Время обработки (ms)).
*   **Результат:** CraftStack на 1GB файле показывает **~40% faster** за счет асинхронного конвейера (85ms против 145ms у Paperclip).

#### **Страница 4: "Performance & Cost Efficiency"**

**Левая часть (CPU Usage Comparison):**
*   **Текст:** "Don't pay for idle threads."
*   **График:** Линейный график (время/загрузка CPU). Линия CraftStack почти плоская (Evented I/O). Линия Paperclip — пики при синхронной загрузке файлов.
*   **Цифра:** CraftStack использует **~30% меньше CPU** на том же hardware при 1000 concurrent uploads.

**Правая часть (Cost Analysis):**
*   **Таблица (годовые затраты для SMB с 500GB хранилища):**
    *   | Item | Paperclip (traditional) | CraftStack (optimized) |
        |---|---|---|
        | Server Cost | $2,400/yr (3x Large instances) | $1,200/yr (2x Medium + caching) |
        | Storage Cost | $600/yr | $600/yr |
        | **Total** | **$3,000/yr** | **$1,800/yr** |
    *   **Итог:** **Save 40% on infrastructure.**

### **Инструкция по сборке PDF:**
1.  Откройте **Canva** (бесплатно).
2.  Выберите шаблон "Modern Tech Presentation".
3.  Вставьте текст из этого документа.
4.  Используйте встроенные элементы Canva для создания:
    *   Таблицы (Page 3).
    *   Столбчатой диаграммы (Page 3, данные выше).
    *   Круговой диаграммы (Page 4, для Cost Analysis).
5.  Скачайте как **PDF (Print)**.
