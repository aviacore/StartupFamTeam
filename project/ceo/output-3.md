```markdown
# Plan_03.md — Список ИИ-агентов для маркетингового дашборда

## Введение
Данный план определяет минимально необходимый набор ИИ-агентов, которые должны быть интегрированы в маркетинговый дашборд. Цель — автоматизация сбора, анализа и генерации инсайтов для ускорения принятия решений. Каждый агент специализируется на одном потоке данных.

## 1. Agent: Data Collector (Сборщик данных)
- **Функция:** Автоматический сбор данных из внешних и внутренних источников (CRM, рекламные кабинеты, коллтрекинг, Google Analytics, соцсети).
- **Выход:** Структурированные таблицы в реальном времени.

## 2. Agent: Competitor Radar (Радар конкурентов)
- **Функция:** Мониторинг цен, выходов новых продуктов, рекламных активностей и изменений на сайтах конкурентов.
- **Выход:** Оповещения в дашборд + сводка «Что нового у конкурентов».

## 3. Agent: Trend Spotter (Тренд-аналитик)
- **Функция:** Анализ поисковых запросов, соцсетей и новостей для выявления сезонных и неожиданных трендов.
- **Выход:** Подсвеченные аномалии на графиках и прогноз изменения спроса.

## 4. Agent: Content Optimizer (Оптимизатор контента)
- **Функция:** Анализ эффективности рекламных креативов, текстов и видео. Предлагает A/B-тесты и гипотезы для заголовков.
- **Выход:** Список рекомендаций по изменению контента.

## 5. Agent: ROI Forecaster (Прогнозист окупаемости)
- **Функция:** Моделирование будущего бюджета и ROI на основе исторических данных (LTV, CAC, сезонность, текущие затраты).
- **Выход:** График прогноза с интервалами достоверности.

## 6. Agent: Anomaly Detector (Детектор аномалий)
- **Функция:** Круглосуточный поиск необычных всплесков/провалов метрик (конверсии, клики, отказы).
- **Выход:** Красные метки на дашборде + автоматическое расследование причины.

## 7. Agent: Audience Segmenter (Сегментатор аудитории)
- **Функция:** Кластеризация пользователей по поведению и интересам. Находит скрытые микросегменты.
- **Выход:** Карта сегментов и рекомендации для ретаргетинга.

## Итоговая структура дашборда
- **Уровень 1 (Стратегический):** ROI Forecaster + Trend Spotter.
- **Уровень 2 (Тактический):** Competitor Radar + Audience Segmenter.
- **Уровень 3 (Операционный):** Data Collector + Anomaly Detector + Content Optimizer.

**Статус:** План принят. Дашборд считается MVP-ready при запуске минимум 4 агентов из списка.
```
