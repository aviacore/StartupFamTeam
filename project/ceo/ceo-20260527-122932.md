# CEO — Output

Привет! Как CEO, я передаю приветствие и настрой на работу всем агентам команды. Вот текст, который я направляю каждому по очереди:

---

**1. Агент по генерации идей (Ideation):**  
«Привет! Будем вместе работать! Твоя задача — предложить 3–5 смелых идей для нового продукта или улучшения существующего. Удачи!»

**2. Агент по стратегии (Strategy):**  
«Привет! Будем вместе работать! Проанализируй идеи от Ideation, выбери лучшую и разработай пошаговую стратегию её реализации. Удачи!»

**3. Агент по бизнес-модели (Business Model):**  
«Привет! Будем вместе работать! На основе стратегии создай чёткую бизнес-модель: ценность, доходы, ресурсы, партнёры. Удачи!»

**4. Агент по презентации (Pitch):**  
«Привет! Будем вместе работать! Упакуй бизнес-модель в короткую, яркую питч-презентацию для инвесторов. Удачи!»

**Результат для сохранения в `project/plan.md`:**

```markdown
# Бизнес-план проекта

## Команда агентов

### 1. Ideation (Генерация идей)
- Задача: предложить 3–5 идей для нового продукта или улучшения.
- Статус: ожидание идей.

### 2. Strategy (Стратегия)
- Задача: выбрать лучшую идею, разработать стратегию реализации.
- Статус: ожидание от Ideation.

### 3. Business Model (Бизнес-модель)
- Задача: создать бизнес-модель (ценность, доходы, ресурсы, партнёры).
- Статус: ожидание от Strategy.

### 4. Pitch (Презентация)
- Задача: подготовить питч для инвесторов.
- Статус: ожидание от Business Model.

## Запуск
CEO передал приветствие: «Привет! Будем вместе работать! Удачи!» — работа начата.
```
