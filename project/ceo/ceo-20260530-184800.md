## Страница 1: Обзор CraftStack

### Легковесная рабочая платформа для AI-агентов

CraftStack — это современная и легкая рабочая платформа для управления AI-агентами, использующая OpenCode и прямые API модели. Наша цель — упростить управление задачами, ускорить проработку идей и повысить производительность стартапов.

- **Пользователь:** CEO и основатели стартапов
- **Язык:** Русский (неформальное общение)

## Страница 2: Преимущества CraftStack

### Почему CraftStack лучше Paperclip?

| Параметр                      | CraftStack                       | Paperclip                          |
|-------------------------------|----------------------------------|------------------------------------|
| **Мощность**                  | Легковесный, оптимизирован для CPU | Тяжелый и требует больше ресурсов   |
| **Скорость выполнения**       | Быстрая обработка задач          | Медленная производительность       |
| **Хранение данных**           | Файловая система (просто и portable) | База данных (сложные зависимости) |
| **Обновления в реальном времени** | Использование SSE для обновлений  | Сложные протоколы WebSocket       |

## Страница 3: Как это работает

### Процесс выполнения задач

1. Пользователь вводит задачу в панели управления.
2. Ассистент начинает выполнение задачи по команде «старт».
3. Прогресс обновляется в режиме реального времени с использованием SSE.
