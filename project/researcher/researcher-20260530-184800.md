### 🔧 Технические Детали

#### Пайплайн Работы

```
1. Пользователь вводит задачу в дашборд
   ↓
2. POST /api/task (сервер записывает task.txt)
   ↓
3. Пользователь говорит «Старт»
   ↓
4. Assistant (OpenCode) читает task.txt и выполняет
   ↓
5. Assistant обновляет state.json → SSE push
   ↓
6. Dashboard проверяет /api/state
   ↓
✅ Task Done!
```

#### Файловая Структура
```
CraftStack/
├── .opencode/modes/    — 8 определений агентов
├── .opencode.jsonc     — Конфиг OpenCode
├── AGENTS.md           — Автозагружаемый файл сессии
├── CONTEXT.md          — Полный контекст проекта
├── server.py           — HTTP сервер (REST API + SSE)
├── dashboard.html      — 3-колоночная доска канбан
├── monitor.html        — SSE монитор реального времени
├── start.bat           — Запуск одним кликом
├── project/            — Артефакты задач
```

### 🌟 Почему CraftStack?

1. **Работает на вашем ноутбуке** — без GPU, без облачных затрат.
2. **Никаких зависимостей** — только Python, который уже есть.
3. **Прозрачность** — вы видите каждый шаг в файлах и мониторе.
4. **8 агентов** — от CEO до QA, все роли в одной системе.
5. **Скорость** — запуск за миллисекунды, обновления в реальном времени.
6. **Портативность** — скопируйте папку на флешку и работайте.
