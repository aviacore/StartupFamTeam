# CraftStack vs Paperclip: Техническое исследование

## Executive Summary

**CraftStack** — легковесная AI Agent Workbench для CPU-only окружений, построенная на OpenCode, файловом хранении и прямом API.

**Paperclip** — open-source платформа управления AI агентами на рабочих местах (⭐68,422, TypeScript).

---

## Сравнительная характеристика

| Параметр | CraftStack | Paperclip |
|---|---|---|
| **Язык** | Python (stdlib) | TypeScript |
| **Звезды GitHub** | — | ⭐68,422 |
| **Версия** | v0.6 (in development) | Production-ready |
| **Развертывание** | Один файл `server.py` | Требует Node.js + npm |
| **Порт по умолчанию** | 8765 | 3000 (обычно) |
| **Хранилище** | Файлы (JSON/txt) | База данных |
| **Обновления** | SSE (Python stdlib) | WebSocket |
| **Дашборд** | Kanban + чат | Полноценный UI |
| **Агенты** | 8 режимов (CEO, PM, CTO, Developer, Designer, Marketer, QA, Analyst) | Неограниченное количество |
| **Модели** | DeepSeek V4 Flash (primary), другие API как fallback | Любые API-модели |
| **GPU** | Не требуется | Рекомендуется |
| **Windows** | Полная поддержка (pythonw.exe) | Через WSL |
| **Консоль** | Без окон (pythonw.exe) | Требуется терминал |
| **Зависимости** | 0 (stdlib only) | npm-пакеты |
| **Сложность** | Минимальная | Средняя/высокая |

## Архитектура

### CraftStack
```
User → Dashboard (POST /api/task) → server.py
                                     ↓
                              task.txt → Assistant (OpenCode)
                                     ↓
                              state.json → SSE → Monitor
                                     ↓
                              project/ (артефакты)
```

### Paperclip
```
User → Web UI → API Server → Agent Manager
                              ↓
                        Агенты (TypeScript)
                              ↓
                        База данных
                              ↓
                        WebSocket → Real-time UI
```

## Ключевые решения CraftStack

| Решение | Причина |
|---|---|
| **Без Paperclip** | Слишком тяжелый для локального железа, избыточный overhead контекста |
| **Без Ollama** | Слишком медленный, модели слабые для CPU-only |
| **DeepSeek V4 Flash** | Бесплатно, сильное кодирование |
| **Файлы вместо БД** | Нет зависимостей, портативно, просто |
| **SSE вместо WebSocket** | Проще, работает с Python stdlib |
| **pythonw.exe** | Нет окна консоли, нет проблем с Unicode |
| **8 режимов агентов** | Роли: CEO, PM, CTO, Developer, Designer, Marketer, QA, Analyst |

## Функциональность

### CraftStack
- ✅ Pipeline: задача → дашборд → API → файл → агент → результат
- ✅ 8 предопределенных режимов агентов
- ✅ Kanban-дашборд (3 колонки: Todo/In Progress/Done)
- ✅ Плавучий чат с ассистентом
- ✅ Монитор реального времени (SSE)
- ✅ Старт задач через команду «старт» в чате
- ✅ Нулевые зависимости (stdlib)
- ✅ Полная поддержка Windows (без WSL)

### Paperclip
- ✅ Управление агентами на рабочих местах
- ✅ Множество агентов одновременно
- ✅ Полноценный веб-интерфейс
- ❌ Не поддерживает Windows без WSL
- ❌ Требует npm и зависимости
- ❌ Предполагает GPU для некоторых задач

## Структура проекта CraftStack

```
/opencode/modes/      — 8 файлов определений агентов
/opencode.jsonc       — Конфигурация OpenCode
/AGENTS.md            — Документация (автозагрузка)
/CONTEXT.md           — Полный контекст проекта
/server.py            — HTTP-сервер (ThreadingHTTPServer) + REST API + SSE
/dashboard.html       — Kanban + карточки провайдеров + чат
/monitor.html         — SSE монитор с автообновлением
/start.bat            — Запуск (kill старых процессов, pythonw.exe, открытие браузера)
/project/             — Артефакты задач
/docs/                — Документация
```

## Вывод

**CraftStack** является минималистичной альтернативой **Paperclip** для окружений, где:
- Отсутствует GPU
- Используется Windows без WSL
- Требуются нулевые зависимости
- Нужна простота развертывания (один `start.bat`)
- Достаточно 8 предопределенных ролей агентов

**Paperclip** — полноценная enterprise-платформа с 68,422 звездами GitHub, но требующая Node.js, базы данных и более мощного окружения.
