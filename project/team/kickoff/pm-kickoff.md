# Задачи: Создание HTML-страницы с формой регистрации (CraftStack Dashboard)

## PM: Разработка формы регистрации пользователя

### Задача 1.1: Верстка HTML-структуры формы регистрации
- **Приоритет:** P0
- **Описание:** Создать HTML-разметку для формы регистрации нового пользователя (CEO/стартап-основатель). Форма должна быть адаптирована под русскоязычную аудиторию, неформальное общение на «ты».
- **Критерии приемки:**
  - Есть поля: Имя, Email, Пароль, Повтор пароля.
  - Есть кнопка «Зарегистрироваться».
  - Есть ссылка «Уже есть аккаунт? Войти».
  - Форма находится в центре страницы.
  - Использован минималистичный дизайн (соответствует концепции CraftStack).
  - Код HTML должен быть валидным.

### Задача 1.2: Стилизация формы (CSS)
- **Приоритет:** P1
- **Описание:** Добавить CSS-стили для формы регистрации: выравнивание, цвета, шрифты, отступы, адаптивность под мобильные устройства.
- **Критерии приемки:**
  - Форма адаптивна (работает на экранах от 320px до 1920px).
  - Поля ввода имеют понятные плейсхолдеры.
  - Кнопка имеет hover-эффект и active-состояние.
  - Цветовая схема соответствует проекту (тёмная тема, акцентные цвета).
  - Шрифт — без засечек (sans-serif), читаемый.

### Задача 1.3: Валидация формы на стороне клиента (JavaScript)
- **Приоритет:** P1
- **Описание:** Добавить JavaScript-валидацию полей перед отправкой: проверка email, совпадение паролей, минимальная длина пароля, обязательность полей.
- **Критерии приемки:**
  - При пустых полях — подсветка красным и сообщение «Заполните это поле».
  - При неверном email — сообщение «Введите корректный email».
  - При несовпадении паролей — сообщение «Пароли не совпадают».
  - Пароль минимум 8 символов — иначе сообщение.
  - После успешной валидации — форма отправляется (или выводится alert/сообщение об успехе).
  - Валидация работает без перезагрузки страницы.

### Задача 1.4: Обработка ошибок и UX
- **Приоритет:** P2
- **Описание:** Добавить обработку ошибок при отправке формы (если сервер вернул ошибку) и улучшить пользовательский опыт: индикатор загрузки, плавные переходы.
- **Критерии приемки:**
  - При ошибке сервера (например, email уже занят) — показывать сообщение над/под формой.
  - Кнопка «Зарегистрироваться» блокируется на время отправки.
  - Показывается спиннер или текст «Отправка...».
  - Сообщения об ошибках и успехе анимированы (fade-in/fade-out).

### Задача 1.5: Базовое тестирование (QA)
- **Приоритет:** P3
- **Описание:** Проверить форму регистрации на корректность работы во всех современных браузерах (Chrome, Firefox, Edge) и на мобильных устройствах (эмуляция).
- **Критерии приемки:**
  - Форма отображается корректно в Chrome, Firefox, Edge (последние версии).
  - На мобильных устройствах (320px, 375px, 414px) форма не ломается.
  - Все поля ввода работают.
  - Валидация срабатывает на все указанные случаи.
  - Отправка формы не вызывает ошибок в консоли браузера.
