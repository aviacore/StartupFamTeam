```markdown
# Plan_03.md: Список ИИ-агентов для дашборда «Маркетинг»

## Цель дашборда
Обеспечить маркетологам полный цикл аналитики и принятия решений: от привлечения трафика до удержания клиентов, с возможностью автоматической генерации гипотез и оптимизации кампаний в реальном времени.

## Перечень ИИ-агентов

1. **Агент «Трафик-аналитик»**  
   *Функция:* Мониторинг источников трафика (organic, paid, social, referral, direct), выявление аномалий (резкий спад/рост), прогнозирование каналов с наибольшим ROI.  
   *Входные данные:* Данные Google Analytics, Яндекс.Метрики, рекламных кабинетов.  
   *Выход:* Рекомендации по перераспределению бюджета.

2. **Агент «Контент-стратег»**  
   *Функция:* Анализ эффективности контента (блоги, видео, лендинги), определение тем с высоким вовлечением, генерация заголовков и кратких брифингов для копирайтеров.  
   *Входные данные:* Метрики постов (CTR, время на странице, конверсия), семантическое ядро.  
   *Выход:* План контента на неделю.

3. **Агент «Сегментатор аудитории»**  
   *Функция:* Кластеризация пользователей по поведению (LTV, частота покупок, интересы), построение персон и выявление неохваченных сегментов.  
   *Входные данные:* CRM, данные веб-аналитики, опросы.  
   *Выход:* Сегменты для персонализации кампаний.

4. **Агент «Оптимизатор рекламы»**  
   *Функция:* A/B-тестирование креативов, автоматическая корректировка ставок на основе CPA/ROAS, предсказание лучшего времени показа.  
   *Входные данные:* API рекламных платформ (Google Ads, VK, Яндекс.Директ).  
   *Выход:* Изменения в кампаниях (без участия человека).

5. **Агент «Аналитик воронки»**  
   *Функция:* Построение воронок конверсий (посещение → лид → продажа), выявление узких мест и причин оттока.  
   *Входные данные:* События из GTM, транзакции.  
   *Выход:* Рекомендации по улучшению UX/UI и автоматизации триггерных писем.

6. **Агент «Прогнозатор LTV»**  
   *Функция:* Предсказание пожизненной ценности клиента на основе первых действий (регистрация, первый заказ), ранжирование клиентов по приоритету удержания.  
   *Входные данные:* История покупок, поведенческие паттерны.  
   *Выход:* Список «рисковых» клиентов для ретаргетинга.

7. **Агент «Монитор репутации»**  
   *Функция:* Сбор упоминаний бренда в соцсетях, отзывах и новостях; сентимент-анализ; оповещение о негативе.  
   *Входные данные:* API соцсетей, парсинг отзовиков.  
   *Выход:* Алерты и дайджест репутации.

## Интеграция в дашборд
- Все агенты работают в фоновом режиме, обновляя данные раз в 1–24 часа.  
- Результаты выводятся в виде виджетов: графики, таблицы, рекомендации с кнопками «Применить».  
- Для сложных решений (например, изменение ставок) требуется подтверждение маркетолога.

## Приоритет внедрения
1. Агент «Трафик-аналитик» + «Аналитик воронки» (базовая аналитика)  
2. Агент «Оптимизатор рекламы» (быстрый ROI)  
3. Агент «Сегментатор аудитории» + «Агент прогноза LTV» (продвинутая персонализация)  
4. Агент «Монитор репутации» (реактивный слой)
```
