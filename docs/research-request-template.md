# Research request template

Use this template when asking the StartupFamTeam Researcher/BA agent for help.
It gives enough context for a fast, sourced answer without a long back-and-forth.

## Copy/paste request

```markdown
## Question

What do you need to decide or learn?

## Requesting role

CEO / CTO / PM / Developer / Designer / Marketer / BA / other:

## Decision type

Choose one or more:

- Compare options
- Find current version/pricing/limits
- Identify competitors or alternatives
- Understand user behavior/problem
- Estimate market/channel/business-model numbers
- Find communities, trends, or acquisition channels
- Validate an assumption

## Context

- Product/project:
- Target user:
- Geography/language:
- Current stack/channel/business model:
- Constraints:

## Required freshness

- Current as of today
- Stable background is enough
- Historical trend needed

## Output needed

- 5-minute short answer
- Short memo
- Table of options
- Simple working model/calculation
- Source list only

## Must include

- Sources:
- Recommendation:
- Risks/trade-offs:
- Follow-up questions, if any:
```

## Examples

### Technical comparison

```markdown
## Question

Should our MVP use Prisma or Drizzle for a Next.js app with Postgres?

## Requesting role

CTO / Developer

## Decision type

- Compare options

## Context

- Product/project: StartupFamTeam MVP
- Target user: early startup operators
- Geography/language: global, English/Russian
- Current stack/channel/business model: Next.js, Postgres, fast prototype
- Constraints: low setup time, easy migrations, good TypeScript support

## Required freshness

- Current as of today

## Output needed

- Table of options

## Must include

- Sources: official docs and recent release/pricing notes
- Recommendation: one default choice for hackathon MVP
- Risks/trade-offs: migration complexity, lock-in, ecosystem maturity
- Follow-up questions, if any: only if decision cannot be made
```

### Business/channel question

```markdown
## Question

Which acquisition channels are most promising for a bootstrapped AI productivity
tool targeting indie founders?

## Requesting role

Marketer / BA

## Decision type

- Find communities, trends, or acquisition channels
- Estimate market/channel/business-model numbers

## Context

- Product/project: AI productivity assistant
- Target user: indie founders and solo makers
- Geography/language: US/EU, English
- Current stack/channel/business model: no paid ads yet, freemium planned
- Constraints: near-zero budget, launch in public, small team

## Required freshness

- Current as of today

## Output needed

- Short memo

## Must include

- Sources: channel/platform pages, community examples, benchmark sources
- Recommendation: top 3 channels to test first
- Risks/trade-offs: saturation, effort, paid vs. organic dependency
- Follow-up questions, if any: measurement setup assumptions
```
