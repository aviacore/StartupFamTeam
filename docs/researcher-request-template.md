# Researcher request template

Use this template when asking the Researcher for help. It keeps requests small,
answerable, and useful for the next team decision.

```md
## Question

What do you need to know?

## Request owner

CEO / CTO / Fullstack / Developer / PM / Designer / Marketer / BA / Assistant

## Decision this should support

What will you decide or do after receiving the answer?

## Scope

- Geography / market:
- Language:
- User segment:
- Platform / stack:
- Budget or pricing constraints:
- Time horizon:

## Output needed

Short answer / comparison table / competitor list / source list /
recommendation / follow-up questions.

## Freshness needed

Current facts required? Yes / No

## Known context

Links, assumptions, prior decisions, or constraints the Researcher should know.
```

## Examples

### Technical

```md
## Question

Compare Prisma and Drizzle for a small Next.js MVP using Postgres.

## Request owner

CTO

## Decision this should support

Pick the ORM/query layer before implementation starts.

## Scope

- Platform / stack: Next.js, TypeScript, Postgres
- Time horizon: MVP first, migration path later

## Output needed

Comparison table and recommendation.

## Freshness needed

Current facts required? Yes

## Known context

Prefer low setup cost and good TypeScript support.
```

### Market

```md
## Question

Who are the main competitors for an AI agent coordination tool for small startup
teams?

## Request owner

Marketer

## Decision this should support

Positioning and landing page messaging.

## Scope

- Geography / market: global, English-speaking startup teams
- User segment: founders and small product teams

## Output needed

Competitor list with positioning, pricing, and differentiation notes.

## Freshness needed

Current facts required? Yes

## Known context

Focus on tools that coordinate multiple AI agents or automate team workflows.
```

### Business analysis

```md
## Question

What business models are common for AI productivity tools sold to small teams?

## Request owner

BA

## Decision this should support

Initial pricing model and KPI assumptions.

## Scope

- Geography / market: US/EU SaaS
- User segment: teams under 20 people
- Budget or pricing constraints: self-serve pricing preferred

## Output needed

Business model options, examples, and risks.

## Freshness needed

Current facts required? Yes

## Known context

We may start with a freemium or trial-based MVP.
```

## Minimum request

If speed matters, send only:

```md
Question:
Owner:
Decision:
Scope:
Output:
```
