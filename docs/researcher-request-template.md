# Researcher request template

Use this template when asking the StartupFamTeam Researcher for facts, comparisons, market context, or source-backed recommendations.

## Copy-paste request

```md
## Research question

...

## Why this is needed

Decision, task, or deliverable this research will support:

...

## Scope

- Geography:
- Audience / segment:
- Product or technology context:
- Time sensitivity:

## Constraints

- Budget:
- Must-have requirements:
- Nice-to-have requirements:
- Exclusions:

## Preferred output

Choose one or more:

- Short recommendation
- Comparison table
- Competitor / alternative list
- Source list
- Risk summary
- Market / trend scan

## Deadline or urgency

...
```

## Minimal request format

If speed matters, send at least:

```md
Question:
Context:
Output needed:
```

Example:

```md
Question: Compare Prisma and Drizzle for a Next.js MVP on Postgres.
Context: We need to choose an ORM/query layer before building auth, billing, and dashboard flows.
Output needed: Short recommendation with trade-offs and sources.
```
