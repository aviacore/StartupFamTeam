# Вопросы по роутеру, пайплайну и результатам

## 1. Роутер (PM)
- Как выбирает агентов под задачу?
- Как распределяет по провайдерам (нагрузка, цена, приоритет)?
- Как управляет параллельностью (complex mode — все сразу, кроме CEO)?
- Как собирает результаты (очередь, мерж)?

## 2. Пайплайн (CEO)
- Граф выполнения: линейный / параллельный / гибрид?
- Фазы: routing → execution → review → merge?
- Обработка ошибок: перезапуск агента / пропуск / стоп?

## 3. Результаты (представление)
- Группировка по агентам или по этапам?
- Формат: md / html / ссылки?
- Куда сохраняются, структура выдачи?
