# Research source catalog

Use this catalog as a starting point for fast Researcher/BA answers. It does not
replace live checking: for versions, pricing, quotas, and legal terms, open the
source and verify the current page before answering.

| Question type | Prefer these sources | Use for |
| --- | --- | --- |
| Search interest | https://trends.google.com/trends | Relative trend direction by region/time |

| Competitor discovery | Product Hunt, G2, Capterra, AlternativeTo, GitHub, app stores | Existing products, positioning, categories |

## Source quality rules

1. Primary source beats secondary source for versions, pricing, quotas, and
   policy claims.
2. Secondary sources are useful for market interpretation, but label them as
   estimates when they estimate traffic, volume, or costs.
3. Community posts are evidence of user language and pain points, not proof of
   market size by themselves.
4. If a source is gated or unavailable, state that limitation and use a public
   alternative.
5. Add the retrieval date for pricing, limits, and trend snapshots.

## Quick citation format

Use short citations in the answer body:

```markdown
- Node.js 22 is an active LTS line according to the official release schedule
  (Node.js Release Working Group, retrieved YYYY-MM-DD): <link>.
- Vercel lists Hobby plan deployment limits on its pricing page (retrieved
  YYYY-MM-DD): <link>.
```

## Red flags

- Exact market-size numbers without methodology.
- Pricing claims copied from old blog posts.
- Search volume presented without region, language, and source.
- "Best" recommendations without criteria.
- Vendor comparisons that only cite one vendor's marketing page.
