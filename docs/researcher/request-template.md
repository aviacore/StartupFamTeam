# Research request template

Use this template when asking the Researcher for a quick answer, market scan, technology comparison, or business benchmark.

## Copy/paste request

```md
## Research question
What do we need to know?

## Decision this supports
What decision will the answer unblock?

## Requester / role
CEO / CTO / Developer / PM / Marketer / Business Analyst / Designer / Assistant

## Context
- Product or feature:
- Target user:
- Geography / language:
- Known constraints:

## Output needed
- Quick answer / comparison table / competitor list / market sizing / pricing benchmark / channel scan
- Preferred depth: hackathon quick answer or decision memo

## Freshness requirement
- Must be current as of today / okay to use stable background knowledge

## Sources to prioritize
- Official docs / pricing pages / market reports / communities / app stores / GitHub / other:

## Deadline or urgency
- Immediate / next heartbeat / before a planning decision
```

## Minimal version

If time is short, send only:

```md
Question:
Decision:
Market/geography:
Output format:
```

## Good examples

### CTO / Developer

```md
Question: Compare Prisma and Drizzle for a small Next.js MVP using Postgres.
Decision: Choose ORM/query layer before implementation.
Market/geography: Not relevant.
Output format: Comparison table with recommendation and official docs links.
```

### PM / CEO

```md
Question: How do solo founders currently validate landing page ideas without a designer?
Decision: Decide whether this is a strong first use case.
Market/geography: English-speaking indie hackers and early-stage founders.
Output format: User workflow summary, alternatives, communities, and gaps.
```

### Marketer

```md
Question: Who are the main competitors for AI startup team orchestration tools?
Decision: Pick positioning for StartupFamTeam landing page.
Market/geography: Global English-speaking startup builders.
Output format: Competitor map, messaging patterns, and opportunity angles.
```

### Business Analyst

```md
Question: What pricing models are common for AI agent orchestration platforms?
Decision: Draft first pricing hypothesis.
Market/geography: Global SaaS.
Output format: Pricing examples, monetization model categories, and assumptions.
```

## Researcher response acceptance criteria

A good Researcher answer should include:

- A short answer or recommendation.
- Key facts with sources.
- Caveats for weak, stale, unavailable, or geography-specific data.
- Clear separation between evidence and assumptions.
- A practical next step when the evidence is incomplete.
